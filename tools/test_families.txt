# Curation rules (conservatism):
#   - only NARROW, high-confidence src leaves get a family; anything
#     wide (compiler frontend, module loader/linker, the opcode
#     dispatcher) stays OUT so T0 falls back to full Debug units;
#   - every family with a src rule MUST declare a unit rule (the mapper
#     treats its absence as a data bug and falls back);
#   - an e2e rule is optional (some families are unit-only).
#
#   family <name> src <glob>      (glob over repo-relative paths)
#   family <name> unit <ctest -R regex fragment>
#   family <name> e2e <manifest-name regex fragment>
#   ignore <glob>
