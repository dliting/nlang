#env_gates.txt -- environment-gated e2e entries.
#`name <capability...>`: the entry's live-success premise needs a
#machine capability that ambient software can revoke (VPN filter
#drivers swallowing ICMP, DNS hijacks answering reserved TLDs). The
#runner probes each capability once via an out-of-band OS oracle and
#skips gated entries, visibly, when the oracle says it is absent.
#Pure-contract entries are never gated. See run_e2e_tests.py
#(ENV_PROBES for the oracle definitions).
#
#  icmp  the OS gets loopback ICMP echo answers (ping exit code)
#  dns   the resolver fails a reserved TLD (.invalid, RFC 2606)
#  fds   the soft RLIMIT_NOFILE covers the concurrency examples' two
#        process-local socket populations (client + server arms);
#        POSIX defaults of 1024 run the 1000-client bench out of
#        descriptors mid-run. Windows has no comparable cliff.

stdlib_net_ping_loopback icmp
stdlib_net_ping_stress icmp
#Both resolver-phrase cases rest on the same premise: the resolver answers
#the reserved TLD with NXDOMAIN. A fake-ip DNS hijack hands out an address
#for `.invalid`, and the case then connects or pings instead of reporting
#"host not found" — so stdlib_net_resolve_text joins the dns group here
#(the dev-side registry added this line; the master-side registry listed
#only the ping case until the two lines were merged).
stdlib_net_ping_error_text dns
stdlib_net_resolve_text dns
#The 1000-client bench: client and server arms live in one process, so
#~2000 sockets must open alongside the std fds — the fds oracle gates
#it (visible SKIP on a constrained host, full run where limits allow).
net_conc_bench fds
