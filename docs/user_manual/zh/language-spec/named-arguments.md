# 命名实参


实参可以用 `name = expr` 语法按名传递。位置实参必须出现在命名实参之前。

```nlang
int foo(int a, int b) { return a * 10 + b; }
foo(a = 5, b = 7);     // 命名，任意顺序
foo(5, b = 7);          // 混合：先位置后命名
foo(b = 7, a = 5);      // 命名，倒序
```

错误：
- `foo(b = 2, 1)` —— 命名后出现位置实参：编译错误
- `foo(1, a = 2)` —— 对 `a` 重复绑定：编译错误
- `foo(c = 1)` —— 未知形参名：编译错误
