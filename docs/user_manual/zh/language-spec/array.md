# 数组

规范性规则见规范§4.3。

数组是定长、可按索引寻址的序列。语法为`T[]`。

### 创建数组

```nlang
int[] a = int[3];         // 表达式位：定长创建，元素零初始化
int[] b = [1, 2, 3];      // 裸方括号字面量
int[] e = [];             // 空数组字面量（int[0]等价）

int d[3];                 // 声明位定长：零填充
int f[100] = [7, 8];      // 声明位部分初始化：余位零填充
```

- **表达式位**：`int[3]`在堆上创建定长数组，元素零初始化；`[1, 2, 3]`是集合字面量形式（花括号形式`{...}`保留给集合、struct与class初始化——`int[] c = {1, 2};`被拒绝），推断与消歧规则见[集合初始化器](collection-initializers.md)。
- **声明位**：`int d[3];`直接声明定长数组并零填充；带初始化器时未列出的元素零填充（`int f[100] = [7, 8];`只填前两个）。逗号分隔列表的每个声明符都可自带`[n]`尺寸（`int a, b[3];`合法）；各声明符类型＝头类型加自身方括号的规则见[声明](declarations.md)。
- 只声明不初始化（`int[] g;`）得到null引用，见[声明](declarations.md)的默认值表。
- 元素类型可以是struct（`Point[3]`为每个元素物化独立值，见[结构体](struct.md)）或class（存引用）。数组的数组（锯齿形态）不支持，见[已知限制](known-limitations.md)。

### 引用语义

数组是**引用类型**：数组在堆上，赋值与参数传递拷贝数组**引用**而非元素。指向同一数组的两个变量观察同一份元素写入。

- **赋值**：`b = a`使`b`指向同一数组对象。
- **参数传递**：传递引用；被调方的元素写入对调用方可见。
- **返回值**：返回引用。
- **作为字段/元素**：以引用存储（见[结构体](struct.md)、[类](class.md)、[内建泛型类](builtin-generic-classes.md)的`List<int[]>`）。

struct类型的数组在行为上是例外：每个元素是值类型，所以`Point[n]`为每个元素物化一份独立的`Point`，读取元素时深拷贝。见[结构体](struct.md)「值语义」。完整的值vs引用摘要见[类型语义](type-semantics.md)。

### 长度

`a.length()`是方法（零参数、返回`int`），与`string.length()`、`List.length()`形态一致。见[字符串](string.md)。

### 下标读写

`arr[i]`读写元素，下标是表达式（可嵌套）：

```nlang
int[] a = int[3];
a[0] = 9;
a[1] = a[0] + 1;
int x = a[a.length() - 1];
```

下标左值的复合赋值（`arr[i] += 1`）受[复合赋值](compound-assignment.md)同一规则约束（元素为string时仅`+=`）。

### 越界

索引越界时读或写都抛`IndexOutOfBoundsException`（运行期错误，可被`try/catch`捕获；未捕获时程序以退出码1终止——内建异常表见[异常](exception.md)）。

尺寸创建同样有界：长度为负、或超过1亿个元素时，在创建点抛`IndexOutOfBoundsException`。该上限覆盖所有创建路径——`T[n]`与tensor包的native铸造一视同仁（最宽元素下1亿个元素为800MB）。

### 数组值可去向

数组值在标量上下文中的去向规则见[已知限制](known-limitations.md)「标量上下文中的数组值」。迭代数组元素用`foreach`（见[foreach](foreach.md)）。用字面量初始化见[集合初始化器](collection-initializers.md)。

### 多维数组

矩形多维数组写作`T[,]`（二维）、`T[,,]`（三维），最多64维。维度数是类型的一部分：`int[,]`与`int[]`是两个无关的类型，互相赋值、互传形参都被编译期拒绝。

```nlang
int[,] grid = int[2, 3];      //2x3，元素零初始化
grid[1, 2] = 7;               //逗号下标读写
int rows = 2;
int[,,] t = int[rows, 1, 2];  //尺寸可以是表达式，运行期判定
```

- **下标**：`a[i, j]`的坐标个数必须等于维度数，多写或少写都是编译期错误；每个坐标是表达式，越界时与一维一样抛`IndexOutOfBoundsException`。复合赋值与一维下标同规则。
- **成员**：`a.rank()`返回维度数；`a.shape()`返回逐维元素个数的一维`int`数组；`a.length()`返回全部元素个数（各维之积）。
- **foreach**：按行主序（最后一维铺得最快）逐个迭代元素，循环变量类型是元素类型。
- **传参与存储**：`int[,]`可作参数、返回类型、字段与容器元素类型，跨模块导入后保持原样；引用语义、string去向等规则与一维一致（见[已知限制](known-limitations.md)）。

初始化器用嵌套方括号字面量，按目标维度逐层嵌套，形状在编译期校验为矩形——嵌套层数等于维度数、同一层各行等宽：

```nlang
int[,] m = [[1, 2], [3, 4]];
int[,,] t = [[[1, 2]], [[3, 4]]];
double half = 0.5;
double[,] w = [[half, half * 2], [0.0, 1.0]];   //元素可以是表达式
```

元素按行主序落入新数组。锯齿字面量（同层各行不等宽）、嵌套层数与维度数不符都是编译期具名拒绝；维度数≥2时字面量必须非空——没有可推断的行就没有维度（一维`int[] a = [];`保持合法）。花括号形式对数组目标维持既有拒绝（见[集合初始化器](collection-initializers.md)）。

声明位尺寸只支持一维（`int b[100]`）；多维数组用`int[2, 3]`创建——`int a[2, 3];`被具名拒绝并引导使用创建式（字段声明位同理须用创建式初始化）。
