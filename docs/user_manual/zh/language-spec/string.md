# 字符串


`string` 是基本类型，但不同于整型、浮点、`bool` 与 `char` 这些标量，它是经
句柄引用的**不可变对象**。本页完整覆盖字符串类型：它是什么、内存语义、如何
构造与比较，以及字面量内的转义序列与插值。

### 值语义

string 在类型系统中是**值类型**：赋值、参数传递、返回都拷贝句柄，`==` 比较
**内容**而非身份。句柄背后的对象不可变，所以共享句柄无害——指向同一字符串
的两个名字永远不会分歧。（对比 `class`，它是引用类型：见 [类](class.md)
与 [类型语义](type-semantics.md)。）

### 编码与长度

字符串字面量以其 Unicode转换格式（UTF-8，Unicode Transformation Format） 字节序列存入模块字符串常量表。`string.length()` 返回
**字节数**，不是 Unicode 码点数——`"héllo".length()` 是 6（5 个码点，但 `é`
在 UTF-8 中占 2 字节）；码点数用 `charCount()`。按字节还是按码点访问字符串
是两条不同的路径——见下方「char 桥接」。`io.print` 把原始字节原样写入标准
输出，控制台看到的就是 UTF-8；完整表示链（源文件、编译后的 char、控制台）
见 [基本类型](primitives.md)「表示链：从源码到控制台」节。

### 内存语义

字符串在运行期是**不可变对象**：拼接、截取等操作都产出新的内容，既有对象的
内容永不改变。string 槽位持有指向字符串对象仓的句柄，句柄 0 表示 null，读取时
按空串处理。

- **常量随模块执行存活**：源代码里的字符串字面量在模块开始执行时物化为常驻
  对象，整个执行期间不会被回收。
- **短串驻留重用**：不超过 40 字节的运行期字符串按内容驻留——相同内容只保留
  一份对象。`==` 比较的仍然是内容，语义不变。
- **追加 O(1)**：`s = s + x` 先记录为一个拼接节点，首次读取时才展平为实际
  内容，循环追加不会逐步拷贝整串。
- **内存有界**：不再被引用的字符串对象由垃圾回收器回收，长时运行的程序
  （如持续构建提示词的循环）内存占用不会无限增长。

### 构造字符串

- **拼接**：`string + string` 与 `string + 标量基本类型`（标量被强制转换——
  见 [类型强制转换](type-casts.md)「基本类型 → string 强制转换」；char 按
  其 UTF-8 编码拼接，`"x" + 'y'` 是 `"xy"`）。
  `string - string` 与其他算术形式是编译错误。
- **插值**：字面量内的 `${identifier}`——见下文。
- **转义序列**：见下文。
- **从基本类型显式构造**：`ToString()` / 基本类型 → string 强制转换——
  见 [类型强制转换](type-casts.md)。

### 比较

`==` / `!=` 比较**内容**。关系排序（`<`、`>`、`<=`、`>=`）用 C `strcmp` 式的
逐字节比较（例如 `"Z" < "a"` 为真，因为 `'Z'`（90）< `'a'`（97））。字符串
是 UTF-8，而 UTF-8 字节顺序等于码点序，因此对非 美国信息交换标准代码（ASCII，American Standard Code for Information Interchange） 文本排序同样正确：
`"é" > "z"` 为真。string 与非 string 混用比较是编译错误，唯一例外是对 null
字面量——`s == null` 把 null 一侧读作空串，因此 `"" == null` 为真，任何非空串
与 null 不等。完整比较规则在 [运算符](operators.md)「比较」节。

### 转义序列

双引号字面量内：

| 转义              | 产生                              |
|-------------------|-----------------------------------|
| `\n` `\r` `\t`    | 换行、回车、制表                  |
| `\\` `\"` `\'`    | 反斜杠、双引号、单引号            |
| `\0` `\a` `\b` `\f` `\v` | NUL、响铃、退格、换页、垂直制表 |
| `\uXXXX`          | 该码点的 UTF-8 编码（4 位十六进制）|

`\uXXXX` 只覆盖 4 位十六进制的 基本多文种平面（BMP，Basic Multilingual Plane） 码点。**相邻的代理区转义按码点组合**：
`"😀"` 即 U+1F600 😀（与 Java 同款）；孤立出现的代理区转义是编译
错误。char 字面量支持同一 `\uXXXX` 形式，但**不接受**代理区（char 排除代理
区码点，见 [基本类型](primitives.md)）。其他转义（如 `\q`、`\x`）是编译
错误——转义序列从不按字面反斜杠对透传。转义与插值可组合：`"${name}\n"`
先插值再追加换行。

### 字符串插值

```nlang
string name = "world";
string s = "Hello ${name}!";   // "Hello world!"
```

NLang 在双引号字符串字面量内支持 `${identifier}` 插值——具名变量的值经与
「基本类型 → string」和「集合 `toString()`」相同的强制转换路径格式化（见
[类型强制转换](type-casts.md)）。插值在编译期被改写为等价的 `OP_Add` 字符串
拼接表达式；不引入任何新指令。

**语法约束**：

- `${...}` 内只支持单个标识符。`${a + b}`、`${obj.method()}`、`${this.x}` 之类
  的复杂表达式在解析阶段被拒绝。请改用单独变量：`int sum = a + b;
  "result=${sum}"`。
- `${name}` 中 `name` 不在作用域内时产生编译错误（"undefined
  identifier"）——与其他任何未定义标识符引用同一路径。
- 空 `${}` 与非法标识符内容（如 `${123}`、`${a b}`）产生编译错误。

**美元转义**：`$$` 产生字面 `$`。`$${name}` 产生字面文本 `${name}`（不插值）。
后面不接 `$` 或 `{` 的孤立 `$` 按字面 `$` 保留。

```nlang
string name = "x";
string a = "$${name}";  // 字面 "${name}"
string b = "price: $";  // 字面 "price: $"
string c = "$$100";     // 字面 "$100"
```

**类型分派**：标识符解析出的类型决定自动施加的强制转换：

| 标识符类型 | 施加的强制转换       |
|-----------|----------------------|
| 标量基本类型（整型家族、`float`/`double`、`bool`、`char`） | `OP_Prim_to_str <kind>` |
| `string`  | 无                   |
| `enum`    | `OP_Enum_to_str`     |
| `Array`   | `OP_Array_to_str`    |
| `List` / `Dict` | `OP_CallMethod "toString"` |
| `class`   | `OP_CallMethod "toString"` |

### char 桥接

string 是 UTF-8 **字节串**，char 是单个 Unicode 标量值（见
[基本类型](primitives.md)）。两者之间的桥接：

- **按字节读**：`s[i]` 返回第 i 个字节的 `ubyte`（越界抛运行期
  错误 `string index out of range`）。
- **按码点迭代**：`foreach (char c in s)` 每次 `c` 是一个完整码点（UTF-8
  解码推进，多字节字符不会被拆开）——见 [Foreach](foreach.md)。
- **按码点定位**：`s.charAt(i)` 返回第 i 字节处开始的码点（`char`）；越界或
  非法序列抛运行期错误。
- **计数**：`s.charCount()` 返回码点数（对比 `s.length()` 字节数）。
- **解析与构造**：`"65".toChar()` 严格十进制码点解析为 `char`；
  `"x" + 'y'` 拼接时 char 按其 UTF-8 编码进入字符串。

### Null

string 槽位可持有 null 句柄（0）。与 null class 引用（成员访问时抛错）不同，
null 字符串**读作空串** `""`——对 null 字符串调用 `s.length()` 返回 0。
class null 的对比语义见 [类](class.md)。
