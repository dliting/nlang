# 已知限制


- **用户自定义泛型**：不支持`class Foo<T> { ... }`。编译器只识别内建泛型类（`List<T>`、`Dict<K,V>`）。
- **string → 数值的`as`被禁止**：`"5" as int`是编译错误（``Invalid cast: `String as Int32` is not allowed``）。等价功能由string方法族覆盖（`toInt`/`toLong`/`toFloat`/`toDouble`/`toBool`/
  `toChar`，见[string方法](stdlib-string.md)）；本条是有意的规格缩窄，不是缺陷。
- **标量上下文中的数组值**：数组值只有两类合法去向——自身数组类型（驻留令牌恒等：声明处与值侧共享每元素类型一枚令牌），与**全部**位置上的`string`目标，整值位置与元素槽一视同仁：string局部变量与字段、返回、拼接、string形参（`f(arr)`）、`io.print(arr)`、数组下标（`string[] sa; sa[0] = arr`）与容器存储（`List<string>`下标与`.add`）——都经运行期toString强制转换（得`"[1, 2]"`）。`null`恒可转换到数组目标。比较位置恒为恒等比较：只对另一个数组或`null`做`==` / `!=`。其余用法一律在编译期被明确拒绝——标量、class、interface、`Object`目标，`as`强制转换（`ia as int`），非数组形参，数值二元操作数（`arr + 1`），关系或跨类型比较（`arr < arr2`、`arr == 5`），条件位置（`if (arr)`），`switch`判别式，方法接收者。跨元素与表示互通的数组转换同样拒绝：`string[] b = ia`、协变上转型`Base[] ba = da`、`enum[]`与`int[]`互转都以 "an array value only converts to the same array
  type" 失败。从`List<T[]>` / `Dict<K,T[]>`取出的元素遵循同一规则；其数组性对编译器可见——作方法接收者或`switch`判别式（`li[0].rank()`、`switch (li.get(0))`）会被明确拒绝，`foreach`可以把它们迭代进数组类型的循环变量（数组值源可直接使用且只求值一次），以数组类型为键的`Dict`按句柄恒等比较。
- **锯齿数组（`T[][]`）**：多维数组声明在编译期被拒绝（"jagged arrays (T[][]) are not supported"）——局部变量、字段、参数、返回类型、`for`/`foreach`循环变量以及泛型类型实参位置都是如此。VM没有多维数组布局；请声明扁平数组，或改用`List<List<T>>`式容器。
- **非推断位上的裸`{...}`**：裸花括号字面量需要带类型目标——作方法调用接收者（`{}.length()`）或命名实参时不推断；请先绑定一个带类型局部。见[集合初始化器](collection-initializers.md)。
- **裸`[]`空初始化**：空字面量对`List<T>`与`Dict<K,V>`目标写作`{}`（`List<T> l = {};`、`Dict<K,V> d = {};`）。数组目标无花括号形式（`int[] a = {};`被拒绝——数组初始化用方括号形式），空数组写`int[0]`或不带初始化声明。词法分析器把`[]`切成单个记号（供数组类型后缀规则使用），裸`[]`不解析为初始化器。
- **裸初始化列表作命名实参**：位置实参从形参类型推断目标；命名实参不推断——请用带类型局部或锚定`Type{...}`形式。
- **定长数组声明：尺寸臂仅支持首声明符**：`int a, b[3];`是语法错误——`b`请单独声明。
- **直接初始化括号臂仅支持首声明符**：`Vec a, b(2);`是语法错误——`b`请单独声明（本页`Vec`指带构造函数的类型示例，见[类](class.md)与[结构体](struct.md)）。
- **混合声明符继承数组类型**：`int a[3], b;`中的兄弟`b`是null的`int[]`（数组类型），不是int。
- **部分初始化是声明位的方括号形式**：`int b[100] = [7, 8];`余位零填充；定长声明上的花括号形式（`int b[100] = {7, 8};`）是语法错误。
- **泛型实例化没有锚定头**：`List<int>{60}`无法解析——请给字面量一个带类型声明（见[集合初始化器](collection-initializers.md)）。
- **花括号字面量内嵌裸花括号无法解析**：请用方括号嵌套（`[[1,2],[3,4]]`）。
- **数组return位裸表被拒绝**：`int[]`函数里`return [1, 2];`是类型错误（容器return可推断）。
- **裸集合字面量不能作foreach源**：`foreach (int x in [1, 2, 3])`报推断错误（"Collection initializer requires an explicit type or an LHS context to infer the target type."）；花括号形态是语法错误。先把字面量绑定到带类型局部再迭代。
- **泛型元素定长数组仅声明形态**：`List<int> a[2];`声明数组；没有表达式位的创建孪生。
- **类体内裸调同类名不是构造调用**：会报「方法需要接收者」类错误；请在表达式位写`Vec(2, 3)`构造。
- **`using`别名声明属于文件序言区**：`using`放在其他顶层声明之后是语法错误。
- **`List<struct>`值语义**：把同一个struct变量加入List两次，共享的是底层堆槽位（装箱层是引用语义）。需要独立元素请使用各自的struct实例。
- **急切物化的成本**：`Point[n]`在创建时分配n+1个堆槽位（数组 + 每元素一个struct）。
- **接口方法的默认参数**：接口方法声明上的默认值合法，按调用点的静态类型解析——接口类型调用省略实参时填充的是接口声明上的默认值（即使实现方法另声明了不同的默认值）；实现方法的默认值不参与接口分派，接口声明未带默认值时调用仍须提供全部实参。覆写与实现签名比对不比默认值（声明带默认值、实现不带同样满足契约）。
- **默认值的方法继承**：派生类覆写不继承基类方法的默认值。每个覆写独立声明自己的默认值。
- **导入struct的实例字段跨模块不可访问**：struct桩不携带字段——对导入struct读写`s.x`是编译错误。构造（`lib.Vec(3, 4);`）与把值传给生产方自己的函数可用，struct字段默认值在分配时照常应用。
- **枚举不能跨模块导入**：`enum`不作为模块成员导出——限定引用（`lib.Color.Red`）报`Type 'Color' is not a member of package 'lib'.`。
- **跨模块同参数数重载**：导入的自由函数、接口静态方法与枚举方法按名字＋参数数匹配；同名同参数数但参数类型不同的两个重载在链接期报显式歧义错误，而非静默错链。
- **参数数上限**：超过64个参数的函数（合理性上限）触发编译期错误。除此之外栈帧布局是动态的——调用参数区与求值暂存区按函数体内观察到的实际调用模式定尺寸。
- **finally体内没有控制流**：`finally`体内出现`break` /
  `continue` / `return` / `throw`是编译错误（finally体不得吞掉在途的控制流或异常）。
- **`super()`只直达直接父类**：没有直接调用祖父构造函数的语法；每个构造函数只转发给自己的直接父级。
- **没有lambda表达式 / 闭包**：只存在对具名函数与方法的引用。绑定方法引用携带接收者状态，覆盖常见的回调场景。
- **`List<func<...>>.contains` / `indexOf`用恒等比较**：指向同一函数的两个引用是不同的堆记录，因此新建的引用永远不会`contains`匹配已存储的引用。与`==`（内容相等）的不一致已记录在案。
- **`const`引导的顶层函数**：`const int f(){}`不可解析，因为`const`入口与const语句走同一条语法路径，前缀`const int f(`与`const int x =`无法区分。`const int x = 5;`正常；顶层const函数目前没有合法写法（函数体内不受影响）。
- **顶层直接初始化的首实参类型线劫持**：`Vec p(base.x);` / `Vec p(a<b);`的首实参以限定名或泛型形式开头时，会被当作类型来解析，从而报一条明确的语法错误。变通：改用赋值初始化`Vec p = Vec(base.x);`（函数体内不受影响）。
- **顶层空参形态不对称**：顶层`Foo f();`会报一条明确的语法错误，因为空参数形式必须属于函数定义：分析器必须在空参函数头与零参直接初始化之间二选一。变通：零参构造用`Foo f = Foo();`，前置声明用`func Foo f();`。函数体内`Foo f();`是零参直接初始化，照常可用。
- **`implements限定名.接口`形式不被文法接受**（如`implements lib.IF`）：须先`import`再用非限定名。
- **类体不能为空**：`class B : A { }`是语法错误，须至少声明一个成员。
