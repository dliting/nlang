# out参数


声明为`out`的形参是写回槽：调用方的局部变量被种入被调方的帧槽中，调用返回
后，被调方的值被拷贝回调用方的变量。

```nlang
int divide(int a, int b, out int rem) {
    rem = a % b;
    return a / b;
}
int r = 0;
int q = divide(17, 5, out r);  // q=3, r=2
```

**语义：**
- out参数是**inout**：被调方看到的参数局部初值是调用方当前的值。
- 写回发生在调用返回后，按槽顺序。
- 调用的返回值在out写回**之前**存入结果变量，所以`int x = f(out x)`在
  返回值赋值时读到旧`x`，随后用被调方的输出覆盖`x`。

**限制：**
- out实参必须是**局部变量**（不能是字段、数组元素、或任意表达式）。否则编
  译错误。
- out参数必须是**4字节标量或class类型**（不能是struct）。struct有变长
  值语义，与固定槽写回机制不兼容。
- 虚/接口分派调用上不能用`out`（编译期不知道具体被调方）。
- 构造函数（`new`）或`super()`调用上不能用`out`。
- 每次调用最多32个out参数。
- `out`是保留关键字。
