# NLang 文档

NLang 是一门面向嵌入与自动化场景的静态类型脚本语言，也是探索 人工智能（AI，artificial intelligence） 友好
语言特性的试验台；自带编译器、字节码虚拟机、调试器与 集成开发环境（IDE，integrated development environment），作为教学/研究
开源项目开发。本站为随 IDE 分发的离线文档。
