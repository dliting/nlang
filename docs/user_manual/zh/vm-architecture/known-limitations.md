# 已知限制

本页汇总当前对用户程序可见的限制，并给出可行的替代做法。

1. **退出码范围**：进程退出码以 32 位原值传递；但 POSIX shell 的
   `$?` 只保留低 8 位（退出码 300 在 bash 下被观察为 44）。测试
   预期值保持 ≤ 255，以便跨观察者一致（详见
   [退出码约定](../language-spec/exit-code-convention.md)）。
2. **没有 super() 调用**：不会自动调用祖先构造函数。
3. **struct 没有方法**：struct 只承载数据。需要行为时请用 class。
4. **没有用户自定义泛型**：不支持 `class Foo<T> { ... }`。编译器只
   识别内建泛型类（`List<T>`、`Dict<K,V>`）。
5. **`List<int>` 存储开销**：每个基本类型元素都装箱进一个堆槽位
   （`RTK_Boxed`）。对值密集的列表，规划中的出路是带非装箱存储的
   `IntList` 特化（推迟到性能分析表明确有需要）。
6. **`List<struct>` 值语义**：把同一个 struct 变量加入两次，共享的
   是底层堆槽位（装箱是引用语义）。需要独立元素时请使用各自的
   struct 实例。
