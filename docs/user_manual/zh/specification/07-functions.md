# 7. 函数与方法

## 7.1 声明形式

函数或方法声明的语法：顶层见§2.2，类、结构体、枚举与接口的成员见§2.4。声明给出返回类型或`void`、一个名字、零个或多个形式参数，以及一个体。不带返回类型的方法声明命名一个构造器（第8章）。

顶层函数不带访问修饰符且不带标志时即为*裸函数*（§2.2）。这一区分纯属语法：在顶层，访问修饰符与`static`、`virtual`标志都被接受且没有效果——它们管辖类成员（第8章）。每个顶层函数在其自身单元内都以裸名可见。跨单元时，裸可见性遵循§3.6，限定名则经导入门到达该函数（§3.6，第12章）；两条路径都不查看修饰符。在顶层只有`native`带有含义（§7.5）。

写作`;`的体声明一个无体的函数：顶层是原生函数（§7.5），或接口中没有默认实现的成员（第8章）。

`void`函数不返回值。`return;`提前退出它（§6.6）；对它的调用只用作语句——对其结果赋值、返回它，或把它用作操作数——都是编译期错误（§5.6）。`void`在任何其他位置都不是类型：`void`类型的局部、字段、参数或数组元素是语法错误。

一个函数至多声明64个形式参数；更多是声明期错误。允许递归。调用深度有界（1000帧）；超过界限抛出*宿主级*执行期错误：宿主报告错误并终止程序，且没有`catch`子句处理它（第9章）。

## 7.2 参数与实参

形式参数属于函数作用域（§3.5），在每次调用时由对应的实参初始化。初始化遵循第4章的值模型：结构体形参收到副本（§4.6），而类、接口、数组或函数形参与实参指代同一个对象（§4.3、§4.7、§4.11）。实参必须可赋值给参数类型（§4.12）。参数与局部变量一样可赋值（§6.2）。

形参可以在任意位置声明默认值`T p = e`（§2.4）。默认表达式在声明的作用域中解析，在调用点求值，于每次省略该实参的调用时求值；它可以引用同一声明中更早的形参。该值必须可赋值给`T`（§4.12）。默认值属于声明：经模块导入的调用以同样的方式填充它们，包括引用更早形参或声明单元中函数的默认值。

调用可以按形参名字绑定实参：`f(name = expr)`。按位置的实参排在所有命名实参之前；命名实参可以按任意顺序出现，按名字而非位置绑定。每个形参至多绑定一次。不是所选候选者（§7.3）的形参的名字是编译期错误。命名实参从左到右求值（§5.1）。构造器调用只接受按位置的实参（§7.3）。

声明为`out T p`（§2.4）的形参是一个inout槽：实参的当前值初始化该形参，被调方返回时，形参的最终值写回实参。写回在调用返回后按参数顺序发生，且调用的返回值先于写回存储：当结果变量与某个`out`实参是同一个变量时，写回是最终的存储。实参必须是局部变量或参数：字段、元素、下标或任意表达式都是编译期错误。下列每一项都是编译期错误：带默认值的`out`形参（§2.4）；结构体类型的`out`形参；带超过32个`out`实参的调用；在构造器或`super()`调用、内建容器方法、虚分派或接口分派的调用、枚举方法或原生函数（§7.5）上使用`out`实参。`out`是保留关键字（第1章）。

## 7.3 重载解析

同一裸池中的顶层函数可以重载：同名、不同参数表（§3.7）。类与结构体成员以其方法重载的方式同样重载构造器（第8章）。

在调用点，编译器在参数数能与实参表匹配的候选者中选择，由默认值填充未绑定的形参（§7.2）。当每个实参都能经隐式转换可赋值给其参数时，候选者是可行的（§4.12）；需要收窄转换的实参使候选者不可行。每个可行候选者按其各实参的转换距离之和计分：完全匹配贡献零，每个隐式转换步贡献一跳。总分最小的候选者被选中。两个或多个候选者在最小总分上打平是歧义，没有可行候选者的调用是错误：两者都是编译期错误。

默认参数不打破打平：把某个形参留给默认值的候选者，与恰好绑定该形参的候选者得分相同，所以`f(1)`面对`f(int)`与`f(int, int = 5)`是歧义的。

构造器调用按同样的距离规则在该类型的各构造器之间解析；其实参按位置匹配，因此不接受命名与`out`实参（§7.2）。

导入函数的各重载在调用点对照导入的签名解析，与单元内部完全一致；链接器把选中的重载连到其在产出单元中的记录（第12章）。

## 7.4 函数值与委托

函数类型`func<R, P1, ..., Pn>`及其类型同一规则见§4.11；引用形式——自由函数、经类型名引用的静态方法、绑定到接收者的实例方法，以及每次调用时迟绑定的虚方法或接口方法——见§5.9。

函数引用只在期望函数类型的地方形成：局部声明、初始化器、赋值、返回、实参、数组元素或花括号条目（§5.8）。没有期望类型时，该引用是编译期错误。所指代的签名必须与期望的函数类型完全一致（§4.11）：没有变异性，参数与结果都不做转换。参数带默认值的函数不能被引用：默认值只在直接调用处填充（§7.2）。枚举方法与原生实例方法不能被引用，带`out`参数的虚方法或接口方法也不能被引用（§7.2）。

绑定引用在值形成时捕获其接收者；经由该引用做的状态改变持续留在接收者对象中。虚方法或接口引用在每次调用时按接收者的运行时类分派（§5.9，第8章）。

函数值以`v(a1, ..., an)`调用（§5.6）；函数类型的字段以`obj.cb(a1, ..., an)`调用。函数类型的局部遮蔽同名的函数（§3.7）。经由函数值的调用不接受命名实参（§7.2）；`out`实参在调用返回后写回（§7.2）。调用null函数值是可在执行期捕获的错误（§5.6）；在null接收者上形成绑定引用，在形成处抛出可捕获的执行期错误。

两个函数值在`==`下相等，当它们指代同一个函数，且对绑定引用而言携带相等的接收者；`!=`是补集，`== null`是允许的。排序比较是编译期错误。函数值经由`toString`渲染（§5.3，第8章）。

函数值不进入`Object`（§4.11）。它不能作`Dict`的键、`switch`的判别式，也不能作序列化方法的目标（第15章）。

## 7.5 原生函数

标志含`native`且体为`;`的声明（§2.2、§2.4）没有体：由宿主在执行期提供实现。原生函数在其他方面表现得像普通函数：默认实参在分派之前于调用点填充（§7.2），跨模块边界亦然。

自由原生函数以`<package>.<name>`为键，其中`<package>`是声明单元的模块路径（第12章），`<name>`是它的名字。类成员原生函数保持其裸名；对实例方法，接收者是第一个宿主实参。首次调用时，宿主为该包载入实现；对单段包的自由原生函数，加载器在宿主搜索路径上寻找`nlang_<package>.dll`。包名超过一段的单元不得声明原生函数：编译期错误。原生函数没有`out`参数（§7.2）。

宿主找不到实现时，该调用抛出宿主级执行期错误（§7.1）。由宿主负责匹配声明的签名：声明与宿主实现之间的不一致不是类型错误，产生未指明的结果（§0.4）。调用约定见§22.4。
