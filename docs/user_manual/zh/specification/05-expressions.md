# 5. 表达式

## 5.1 求值顺序

表达式的语法见§2.6，运算符优先级与结合性由§2.7固定。表达式的子表达式按语法呈现的顺序从左到右求值：运算符的左操作数先于右操作数，成员访问的接收者先于调用的实参，调用的实参按顺序，下标的各索引按顺序。每个子表达式完全求值——包括其副作用——之后下一个才开始；实现MUST NOT重排或省略具有可观察副作用的子表达式。

逻辑运算符`&&`与`||`从左到右且短路：右操作数只在左操作数尚未决定结果时才求值——对`&&`是左操作数为`true`时，对`||`是左操作数为`false`时。`&&`、`||`与`!`的操作数是`bool`（§4.2）：不接受其他类型。

## 5.2 算术与关系运算符

二元运算符`+ - * / % << >> < <= > >= == != && ||`与一元运算符`- + !`由§2.7固定。本节固定它们的操作数类型与结果。

`bool`与`char`不参与算术（§4.2）。枚举以`int`的身份参与算术（§4.5）。对一个二元数值运算符，两个操作数取一个*公共类型*：

- 若任一操作数是浮点：任一操作数是`double`时为`double`，否则为`float`；
- 否则两个操作数都是整数：每个比`int`窄的操作数先变为`int`；若此后两者同型，该型即公共类型；否则公共类型是值域同时包含两者的最小整数类型，而当没有整数类型能同时包含两者——如`int`与`ulong`——该运算是编译期错误。

两个操作数都转换到公共类型（§4.12），结果具有公共类型。

`+ - * /`与`%`对每个数值类型都有定义。整数算术按结果类型的宽度取模回绕（§4.2）。整数`/`把商向零截断，`%`取被除数的符号：`(−7)/2`是`−3`，`(−7)%3`是`−1`，`7%(−3)`是`1`。浮点算术在操作数宽度上遵循IEEE 754；`NaN`不等于自身。浮点`%`是取被除数符号的余数：`(−7.5)%2.0`是`−1.5`。

对每个数值类型——包括浮点类型——除以零或对零取余都是执行期错误——浮点除零不产生无穷大。该错误以可捕获的异常在运算符处抛出（第9章）。

`<<`与`>>`移位任意整数类型的整数左操作数（§4.2）；`byte`、`ubyte`、`short`或`ushort`的左操作数先提升为`int`，结果具有提升后左操作数的类型。计数操作数必须可赋值给该类型（§4.12）。计数落在`0`到左操作数宽度减一之外，是以可捕获异常抛出的执行期错误（第9章）；该检查是执行期检查，所以常量计数的越界不是编译期错误。`>>`是算术移位：空出的高位取符号位的值，因此`−8 >> 1`是`−4`。

`<`、`<=`、`>`与`>=`对数值类型（提升之后）、对`char`按码点值、对`string`按§4.4的字节序、对枚举按`int`都有定义。`bool`值不可排序：对`bool`操作数排序是编译期错误。`==`与`!=`对数值类型（提升之后）、对`char`按码点值、对`string`按内容（§4.4）、对`bool`、对枚举按值、对类、接口与`Object`引用按身份都有定义（§4.7、§4.8、§4.9）。

一元`-`与`+`对每个数值类型都有定义，结果具有操作数的类型；对无符号整数取`-`会回绕（§4.2）。一元`!`接受`bool`操作数（§5.1）。

## 5.3 字符串拼接

任一侧有`string`操作数的`+`运算符是字符串拼接：另一操作数转换到`string`（§4.12），两个字节序列接在一起；结果是`string`。`+`左结合，所以`2 + 3 + "y"`是`"5y"`，`"y" + 2 + 3`是`"y23"`。

值到`string`的转换把它渲染为文本：

- 整数：十进制数字，负数带前导`-`，无前导零、无分隔符；
- `bool`：`true`或`false`；
- `char`：单个码点；
- `float`与`double`：在该类型宽度上能精确往返的最短有效数字序列，十进制指数不小于−4且小于16时写作定点记数法，否则写作科学记数法——`1000000`、`1.2e-06`与`1.5`按所写渲染；`NaN`渲染为`nan`，无穷大渲染为`inf`或`-inf`，零渲染为`0`或`-0`；
- 枚举：携带该值的成员的名字（§4.5）。

类、数组或函数值经由其`toString`渲染（第8章）。

## 5.4 字符串插值

字符串字面量可以包含`${name}`，其中`name`是一个标识符：每处出现都代表`name`所指代的值的字符串渲染。名字按裸名解析（第3章），并按§5.3渲染；带插值的字面量与其各部分从左到右求值的拼接等价（§5.1）。

`${`与`}`之间只允许裸标识符。任何其他形式——表达式、限定名、成员访问——都是编译期错误。

## 5.5 类型转换表达式

`e as T`把`e`的值转换到类型`T`。

在编译期，当转换是下列之一时，`as`在两个类型之间有定义：

- 同一类型——包括到祖先类或到`Object`的向上转型（它们是空操作，§4.7、§4.9），以及枚举与`int`之间的互转（§4.5）；
- 装箱进入`Object`（§4.9）；
- 从类类型到其某个后代类的向下转型；
- 从`Object`拆箱到标量基本类型、`string`或枚举；
- 显式数值转换：收窄或变号的整数转换、`float`或`double`到整数，或`char`与整数之间的互转；
- 函数值到`string`；该转换带不带运算符都适用，渲染方式由§5.3固定。

不属于上述之一的隐式转换——整数加宽、整数到浮点类型、`float`到`double`，或除函数值外任何类型到`string`——配`as`是编译期错误：它们不带运算符就适用（§4.12）。没有转换路径的一对类型是编译期错误；`bool`与除`Object`之外的任何类型之间都没有`as`路径（§4.2）：它到`string`的转换是隐式的、不需要运算符。

在执行期：

- 数值类型之间：`float`或`double`到整数把小数部分向零截断，所以`7.9`变为`7`、`−3.7`变为`−3`；整数到另一个整数保留目标宽度的低位，所以`300 as byte`是`44`；
- 到`char`：值必须是Unicode标量值（§4.2）；否则该转换抛出可捕获的执行期错误（第9章）；
- 引用到类类型的向下转型：当值是该类的实例或其子类的实例时，得到同一引用；否则抛出可捕获的执行期错误（第9章）；
- `Object`到标量基本类型或`string`的拆箱：当盒子装有目标类型的值时把装箱的值读出；否则在宿主级失败（第9章）；到枚举的拆箱：当盒子装有`int`值时读出该值，否则在宿主级失败（第9章）；该值不对照§4.5的成员表检查；
- `null`引用的向下转型或拆箱在宿主级失败（第9章），而`null`引用的向上转型得到`null`；
- 枚举转换不做检查（§4.5）。

## 5.6 调用

调用`f(a1, ..., an)`从左到右求值被调方与实参（§5.1）。每个实参必须可赋值给其参数的类型（§4.12）。调用的结果是被调方的返回类型；对`void`函数的调用用作语句（第6章）。调用值为`null`的函数值是可在执行期捕获的错误（第9章）。默认实参、命名实参、`out`参数与重载在第7章定义。

## 5.7 成员访问与下标

`x.m`选取`x`的值的成员`m`；成员查找与分派在第8章定义。经由`null`的类或接口引用访问成员或调用方法，是可在执行期捕获的错误（§4.7，第9章）。

数组下标`a[i1, i2, ..., ik]`携带与数组秩恰好相等的索引数——数目不同是编译期错误——且每个索引是整数表达式。索引落在`0`到其维度长度减一之外，是可在执行期捕获的错误，读与写皆然（第9章）。下标读取给出所存元素；对结构体类型的元素给出副本（§4.3）。下标写入存入一个可赋值给元素类型的值（§4.12）。

字符串下标`s[i]`把字节偏移`i`处的字节以`ubyte`读出；索引必须是整数表达式，越界索引是可在执行期捕获的错误（第9章）。字符串下标只读：经由它写入是编译期错误（§4.4）。按码点访问用`charAt`方法（第13章）。

`List`或`Dict`的下标是其`get`与`set`方法的语法糖（第13章）：`li[i]`读写位置`i`处的元素，越界错误相同；`d[k]`读写键`k`下所存的值——读取映射中不存在的键是可在执行期捕获的错误（§4.10，第9章）。

## 5.8 初始化器与创建表达式

数组创建`T[n]`或`T[n1, ..., nk]`按类型的每个维度给出一个长度（§4.3）。长度是整数表达式；§4.3的执行期约束在创建处检查。

数组字面量`[e1, ..., en]`创建一个秩1数组。目标类型固定元素类型，每个元素转换到它（§4.12）；没有目标类型时，各元素必须同型，该型成为元素类型。对秩大于1的类型，字面量的字面量逐维填充——`int[,] m = [[1, 2], [3, 4]];`——且每一行必须等长，因为数组值的形状永不改变（§4.3）。叶子层之上，条目还可以是一个值为其目标低一维数组的表达式；有这样的条目时，形状在执行期由第一个条目的值固定，后续宽度不同的条目抛出可捕获的异常（第9章）。

结构体花括号初始化器`T{...}`按名字（`T{f: v, ...}`）或按声明顺序按位置（`T{v, ...}`）填充一个新结构体值的字段；省略的字段保持其默认值（§4.6）。类由`T(args)`创建：该调用分配一个新实例并运行构造器（第8章）。`List`或`Dict`由§2.6定义的花括号初始化器创建——按位置的条目追加进`List`，`key: value`条目存入`Dict`——各条目从左到右求值（§5.1）。

## 5.9 函数值表达式

不带调用书写的函数或方法名是一个函数值（§4.11）：

- 自由函数名指代该函数；
- `C.m`指代类`C`的静态方法；
- `expr.m`指代绑定到`expr`的值的实例方法：接收者在函数值形成时被捕获；
- 对虚方法或接口方法的绑定引用，在每次调用时按接收者的运行时类分派（第8章）。

值的类型是`func<R, P1, ..., Pn>`，与所指代函数的签名完全一致（§4.11）。函数值以`v(a1, ..., an)`调用（§5.6）。
