# 18. tensor包

`tensor`包针对`int`、`long`、`float`与`double`四种元素种类的数组提供数值核函数。张量值就是普通数组（§4.3）：该包不引入新类型，元素用§5的下标读写，§4.3的数组成员原样适用。§18.1固定包形态；§18.2定义构造与形状操作；§18.3定义逐元素核函数与归约；§18.4定义矩阵乘积；§18.5固定错误模型。

## 18.1 包形态

`tensor`是标准库包（§12.4）：`import tensor;`把它带入作用域，每个函数都经包限定符调用（`tensor.add(a, b)`）。包名是单段的（§3.3）。它的声明是标准库的`.n`源码；核函数是由随工具链发布的原生库实现的`native`函数（§7.5）。每个核函数都是阻塞的原生函数：它声明阻塞段（§11.1），所以在核函数运行期间调用上下文停泊、载体锁被释放。实参准入是§15.1的包规则。

每个家族都使用同名重载：编译器按实参类型挑选声明，所以元素种类来自带类型的实参——`full`的填充值、`arange`的数列三元组、其余各处的数组操作数。精确的实参匹配优先于更宽的匹配：`arange(0, 10, -3)`选中`int`重载。带后缀的按种类声明（`fullI`、`arangeD`及其家族）是重载的内部实现，不属于文档面。

## 18.2 构造与形状

- `full(n, value)`返回由`value`的`n`个副本构成的数组；元素类型是`value`的类型。
- `arange(start, stop, step)`返回严格在`stop`之前的半开等差数列`start`、`start + step`、……；元素类型是三个参数的公共类型。
- 零填充的数组不需要核函数：定长创建`T[n]`即零初始化（§4.3）。
- `reshape1`–`reshape8`把扁平的源数组`a`重排为名字所带秩的形状，按行主序填充。`int[]`的`shape`必须恰好有那么多维，且各维之积必须等于`a`的元素数。声明面覆盖目标秩1–8；§4.3的全局秩上限是64。
- `flatten(a)`把秩2数组`a`按行主序作为秩1数组返回。
- `transpose(a)`把秩2数组`a`按行主序作为`[cols, rows]`返回。

## 18.3 逐元素核函数与归约

- `add(a, b)`、`sub(a, b)`、`mul(a, b)`与`div(a, b)`逐元素施加运算符，返回操作数元素类型的数组。操作数必须长度相等（秩1）或形状相等（秩2）。整数`div`除零抛出`DivByZeroException`（§9.3）；`float`与`double`除法遵循IEEE，产出Inf或NaN（§4.2）。
- `sum(a)`以元素类型返回所有元素之和；空数组产出该类型的零值。
- `max(a)`与`min(a)`以元素类型返回最大与最小元素；空数组抛出`Exception`（§9.3）。
- `mean(a)`对每种元素类型都以`double`返回算术平均值；空数组抛出`Exception`。
- `dot(a, b)`返回两个等长数组的内积。`int`与`long`重载以64位累加并返回`long`；`float`与`double`重载返回自身类型。空数组产出零。

对秩2操作数，逐元素核函数保持操作数的形状，归约则按行主序把各元素摊平后进行。

## 18.4 矩阵核函数

`matmul(a, b)`返回两个秩2数组的矩阵乘积：`[aRows, aCols] * [bRows, bCols]`产出`[aRows, bCols]`，且内部维度必须匹配。算术遵循全语言统一的规则（§4.2）：`int`与`long`回绕，`float`与`double`遵循IEEE。

## 18.5 错误行为

每次张量失败都是`Exception`家族的一个可捕获值（§9.3）。`null`数组实参抛出`NullPointerException`。负的创建长度、或越过§4.3创建上限的元素数，在创建位点抛出`IndexOutOfBoundsException`；负的`reshape`维度抛出同一个类。`arange`在生成之前检查其元素数，数列会超出上限时抛出`Exception`。零的`arange`步长、或无法朝`stop`推进的步长，抛出`Exception`。双操作数核函数中的长度或形状不匹配、`reshape`的形状其长度与目标秩不符或其乘积与元素数不符，以及对空数组调用`max`、`min`或`mean`，都抛出`Exception`；形状与长度不匹配的消息会点名两侧。

> 实现注记。核函数经由固定视图读写数组载荷，所以一次核函数调用取代一整个解释器循环。
