# 4.7 结构体

## 4.7.1 声明与成员

结构体是用`struct`声明的值类型（§2.4）。它的成员是字段与构造器；结构体没有方法。结构体成员始终是public：字段与构造器默认`public`，在结构体成员上写出`private`或`protected`是编译期错误。

```nlang
struct Point {
    int x;
    int y;
}
```

*资料性：*结构体是无隐藏状态的纯数据记录，因此封装规则对它不适用；行为归类承载。

## 4.7.2 字段初始化器

字段可以声明初始化器。结构体的默认值是各字段的默认值：有声明的初始化器时用初始化器，否则用该类型的默认值。

结构体字段可以携带编译期常量初始化器，表达式规则与类字段相同（§4.8.3）。与类不同，默认值在每次分配时应用，而非注入构造器：裸声明、数组元素、嵌套结构体字段与不完整的初始化器列表都会物化默认值，初始化器条目则覆盖它们；拷贝复制所存的值，不重新应用默认值。

```nlang
struct Point {
    int x = 3;
    int y = 4;
    string tag = "pt";
}
```

*资料性：*默认值保存在编译产物的结构体记录里，因此`import`之后依然可见（[模块序列化](../../vm-architecture/module-serialization.md)）。

## 4.7.3 构造器

结构体可以声明构造器。结构体构造器以类构造器的语法声明（§4.8.6），可以重载（§7.3）。构造器只在显式构造时运行——构造调用`T(args)`或直接初始化声明`T x(args)`；裸声明与初始化器列表填充字段而不运行任何构造器（§4.7.5）。结构体构造调用只接受位置实参（§7.2）。

```nlang
Point p(2, 3);                  // 直接初始化声明
Point q = Point(1, 4);          // 构造调用，赋值
Point r;                        // 裸声明：不运行构造器
Point s = Point{5};             // 初始化列表：不运行构造器
```

上面的构造调用是普通表达式：它产出一个结构体值，赋给声明目标时按§4.7.4把值拷入该位置已有的记录。

## 4.7.4 值语义

结构体值之间的赋值把源的值写入目标位置已有的那条记录：每个字段单元都被覆盖，包括嵌套结构体字段，因此源与目标相互独立。引用类型的字段复制其引用，因此两个结构体值此后共享那个对象（第9章）。

每个结构体存储位置——局部变量、字段、数组元素、容器元素、静态槽位——自建立起拥有终生不变的一条堆记录；向既有位置写入是**原位更新**：覆盖那条记录的字段单元，不分配新记录。只有建立新存储位置的场合才分配记录并填入初始值：

- **声明**（`Point p;`）建立局部记录，给每个字段默认值（§4.7.2）。
- **参数传递与返回**各建立一份新记录并从源拷贝：传入一次、返回一次；被调方操作的是自己那份副本。
- **作为类字段**：`obj.s = s1`把`s1`的值原位写入该字段已有的记录。
- **作为静态字段的值**：类或接口的静态槽位（静态字段、静态常量的懒惰通道、struct类型的静态局部变量）拥有终生一条记录——首次存入建立（或填充无初始化器槽位的类型默认记录），后续每次存入都原位更新；把槽位读入变量时按值拷贝建立新记录，经槽位的成员写入改动槽位自己的记录（§4.8.8）。
- **作为数组元素**：`Point[n]`在创建时为每个元素建立全新、独立的记录，嵌套结构体字段亦然。把元素读入结构体变量时按值拷贝；经下标写入则原位更新该元素已有的记录（§4.10）。零长度结构体数组合法，且不创建任何元素。
- **作为容器元素**：`List<T>`与`Dict<K,T>`的`set`把结构体值原位写入该位置的记录，存入新键时为新位置建立记录（第12章）。
- **相等**（`==` / `!=`）按字段值比较：嵌套结构体字段递归，`string`字段比较内容，引用形态字段（class、数组、接口、`func`）比较同一性——与记录所存的内容一一对应。不同类型的两个结构体永不相等，对结构体排序是编译错误（§4.5）。

结构体含类类型字段时，该类的引用在拷贝时原样复制：原件与副本指代堆上同一个类对象。

```nlang
class Inner { public int x; }
struct Wrapper { public Inner ref; }

int main() {
    Inner obj = Inner();
    obj.x = 10;
    Wrapper a;
    a.ref = obj;
    Wrapper b = a;       // 浅拷贝：b.ref == a.ref（同一对象）
    b.ref.x = 99;        // 修改共享的Inner对象
    return a.ref.x;      // 返回99，不是10
}
```

*资料性：*这种「深拷贝加共享引用」的模型与主流带值聚合的语言对引用类型成员的处理一致。

## 4.7.5 创建与初始化

花括号初始化器列表按名字或按位置填充字段；被省略的字段保持其默认值。

- **具名条目**`Point{x: 1, y: 2}`按字段名赋值。
- **位置条目**`Point{3, 7}`按字段声明顺序赋值；可以只给前几个字段——`Point{5}`只填`x`，其余保持默认值。

字段通过成员表达式`p.x`读写；构造器内可用`this`指名一个字段（§4.8.7）。完整的初始化器列表规则——包括列表可以瞄准的目标形状——见第5章与[集合初始化器](../05-expressions/initializers.md)。

## 4.7.6 跨模块的结构体

导入的结构体是完整的模块成员：其`public`字段跨模块边界可读写，且花括号初始化器按导入的字段列表按名字填充字段（[包](../03-program-structure/packages.md)）。

```nlang lib.n
struct Vec {
    int x;
    int y;
}
```

```nlang
import lib;

lib.Vec v = {x: 1, y: 2};   // 按字段名花括号初始化
v.x = 10;                   // 写导入字段
int sum = v.x + v.y;        // 读导入字段
```

字段访问遵循到哪都相同的可见性规则：只有`public`字段跨边界可达——结构体字段除非显式写出，否则为`public`。若结构体声明了构造器，`lib.Vec(3, 4)`跨边界调用它。生产方的字段默认值随编译产物记录携带，因此不带初始化器声明的导入结构体会像在本模块内一样物化这些默认值（§4.7.2）。

## 4.7.7 输出

结构体没有`toString`，也不参与字符串强制转换：`"x" + 结构体值`是编译期错误。`toString`协议见[类型强制转换](casts.md)。

## 4.7.8 const结构体

`const struct`把类型级不可变语义带给结构体；完整规则见§4.8.12。字段只在自身构造器体与字段初始化器里可写，其余位置的写入是编译期错误。`List`或`Dict`字段读取返回副本（§12.1、§12.2），字段类型面同样受约束。struct没有继承，各自密封。

```nlang
const struct Size {
    int w;
    int h;
}

int main() {
    Size s = Size{3, 4};   // 初始化列表在分配时填值，合法
    int area = s.w * s.h;  // 读取正常
    // s.w = 5;            // 编译错误："w" is immutable
    return area;
}
```

## 4.7.9 引用（`T&`）

值类型——标量、枚举、字符串与结构体记录——默认保持值语义：赋值即拷贝，每个名字拥有自己的存储。`&`记号让一个具体的名字改为**别名既有存储**而非拷贝：

```nlang
int q = 10;
int& r = q;    // r指名q的存储——不做拷贝
r = 20;        // 写入q的存储：现在q == 20
```

**`r = q`永不重新绑定。**对引用的赋值写的是它已经指名的存储。引用在声明处绑定一次，整个生存期都指向那里——要指向别处，另声明一个引用。对照：

```nlang
int a = 1;
int b = 2;
int& r = a;
r = b;         // 把b的值写进a的存储：a == 2，r仍指名a
int& s = r;    // 编译错误："cannot bind a reference to reference"
```

引用出现在四个位置：

- **局部绑定**——`int& r = q;`（上面的例子）。
- **形参**——`void bump(int& v)`：通过`v`的写入落到调用方的实参（§7.2）。
- **返回**——`Point& corner()`：调用结果指名别处拥有的存储；返回局部变量的引用以"cannot return a reference to local …; its storage ends with the call."失败。引用返回实现于游离函数和类方法；接口或枚举方法声明引用返回是编译期错误。
- **循环变量**——`foreach (int& n in nums)`：每一轮指名当前元素的存储（§6.8）。

**可绑定族**：标量、字符串、结构体的存储——局部变量、形参、结构体字段、数组元素，以及经该族值到达的容器元素。身份类型（class、数组、接口、`func`）本身就是引用，其上的`&`是等价记号。绑定要求**精确类型**——转换会建立新存储、破坏别名指向，因此`cannot bind int to long&; a reference binding requires the exact type.`同样拒绝枚举到整数、数值拓宽等形态。

**记录稳定化**是让绑定安全的模型：结构体局部的存储是一条稳定记录。赋值`b = a`原位改写该记录的单元；新记录只在建立场景出现——不带拷贝的声明、数组元素创建、初始化器物化。绑定所指名的记录永不移动，因此绑定不会悬空。

**只读引用**（`const T&`，§7.2）绑定const存储与常量而不允许经绑定写入；表达式结果物化为一个由绑定保活的临时值。可写`&`指向const存储被拒绝："cannot bind a reference to const storage …; a reference may write through its target."

同样在编译期拒绝的形态：指向切片的引用（"a reference cannot bind a slice; slices are views, not element storage."）、指向枚举成员的引用（"cannot bind a reference to enum member"）、指向方法调用结果的引用，以及`Dict`或`string`源上的`&`循环变量。
