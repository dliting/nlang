# 4.7 结构体

## 4.7.1 声明与成员

结构体是用`struct`声明的值类型（§2.4）。它的成员是字段与构造器；结构体没有方法。结构体成员始终是public：字段与构造器默认`public`，在结构体成员上写出`private`或`protected`是编译期错误。

```nlang
struct Point {
    int x;
    int y;
}
```

*资料性：*结构体是无隐藏状态的纯数据记录，因此封装规则对它不适用；行为归类承载。

## 4.7.2 字段初始化器

字段可以声明初始化器。结构体的默认值是各字段的默认值：有声明的初始化器时用初始化器，否则用该类型的默认值。

结构体字段可以携带编译期常量初始化器，表达式规则与类字段相同（§4.8.3）。与类不同，默认值在每次分配时应用，而非注入构造器：裸声明、数组元素、嵌套结构体字段与不完整的初始化器列表都会物化默认值，初始化器条目则覆盖它们；拷贝复制所存的值，不重新应用默认值。

```nlang
struct Point {
    int x = 3;
    int y = 4;
    string tag = "pt";
}
```

*资料性：*默认值保存在编译产物的结构体记录里，因此`import`之后依然可见（[模块序列化](../../vm-architecture/module-serialization.md)）。

## 4.7.3 构造器

结构体可以声明构造器。结构体构造器以类构造器的语法声明（§4.8.6），可以重载（§7.3）。构造器只在显式构造时运行——构造调用`T(args)`或直接初始化声明`T x(args)`；裸声明与初始化器列表填充字段而不运行任何构造器（§4.7.5）。结构体构造调用只接受位置实参（§7.2）。

```nlang
Point p(2, 3);                  // 直接初始化声明
Point q = Point(1, 4);          // 构造调用，赋值
Point r;                        // 裸声明：不运行构造器
Point s = Point{5};             // 初始化列表：不运行构造器
```

`new Point(...)`同样运行构造器；值被放到堆上，与类类型的`new`一致（§4.8.4）。

## 4.7.4 值语义

结构体值之间的赋值复制整个值：每个字段都被复制，包括嵌套结构体字段，因此源与拷贝相互独立。引用类型的字段复制其引用，因此两个结构体值此后共享那个对象（第9章）。

同样的深拷贝适用于结构体值移动的每个场合：

- **声明**（`Point p;`）给每个字段默认值（§4.7.2）。
- **参数传递与返回**各深拷贝一次：传入一次、返回一次；被调方操作的是自己那份副本。
- **作为类字段**：`obj.s = s1`把`s1`深拷贝进该类的字段。
- **作为数组元素**：`Point[n]`在创建时为每个元素分配一个全新、独立的结构体实例，嵌套结构体字段亦然。把元素读入结构体变量时深拷贝；经下标写入则存入数组自己的元素（§4.10）。零长度结构体数组合法，且不创建任何元素。

结构体含类类型字段时，该类的引用在拷贝时原样复制：原件与副本指代堆上同一个类对象。

```nlang
class Inner { public int x; }
struct Wrapper { public Inner ref; }

int main() {
    Inner obj = Inner();
    obj.x = 10;
    Wrapper a;
    a.ref = obj;
    Wrapper b = a;       // 浅拷贝：b.ref == a.ref（同一对象）
    b.ref.x = 99;        // 修改共享的Inner对象
    return a.ref.x;      // 返回99，不是10
}
```

*资料性：*这种「深拷贝加共享引用」的模型与主流带值聚合的语言对引用类型成员的处理一致。

## 4.7.5 创建与初始化

花括号初始化器列表按名字或按位置填充字段；被省略的字段保持其默认值。

- **具名条目**`Point{x: 1, y: 2}`按字段名赋值。
- **位置条目**`Point{3, 7}`按字段声明顺序赋值；可以只给前几个字段——`Point{5}`只填`x`，其余保持默认值。

字段通过成员表达式`p.x`读写；构造器内可用`this`指名一个字段（§4.8.7）。完整的初始化器列表规则——包括列表可以瞄准的目标形状——见第5章与[集合初始化器](../05-expressions/initializers.md)。

## 4.7.6 跨模块的结构体

导入的结构体是完整的模块成员：其`public`字段跨模块边界可读写，且花括号初始化器按导入的字段列表按名字填充字段（[包](../03-program-structure/packages.md)）。

```nlang lib.n
struct Vec {
    int x;
    int y;
}
```

```nlang
import lib;

lib.Vec v = {x: 1, y: 2};   // 按字段名花括号初始化
v.x = 10;                   // 写导入字段
int sum = v.x + v.y;        // 读导入字段
```

字段访问遵循到哪都相同的可见性规则：只有`public`字段跨边界可达——结构体字段除非显式写出，否则为`public`。若结构体声明了构造器，`lib.Vec(3, 4)`跨边界调用它。生产方的字段默认值随编译产物记录携带，因此不带初始化器声明的导入结构体会像在本模块内一样物化这些默认值（§4.7.2）。

## 4.7.7 输出

结构体没有`toString`，也不参与字符串强制转换：`"x" + 结构体值`是编译期错误。`toString`协议见[类型强制转换](casts.md)。
