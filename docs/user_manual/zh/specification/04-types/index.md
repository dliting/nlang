# 4. 类型

## 4.1 类型类别与类型同一性

每个表达式恰有一个类型。类型有：

- 基本类型：§4.2的十二个标量类型与`string`（§4.3）；
- 数组类型（§4.10）；
- 枚举类型（§4.6）；
- 结构体类型（§4.7）；
- 类类型（§4.8）；
- 接口类型（§4.9）；
- 类`Object`（§4.11）；
- 泛型容器类型`List`与`Dict`（§4.12）；
- 函数类型（§4.13）。

类型分入两个值类别。*值类型*是标量基本类型、枚举类型与结构体类型：值类型的变量持有值本身，赋值会复制它。*引用类型*是类、接口与`Object`类型、数组类型、`List`与`Dict`的实例化以及函数类型：引用类型的变量持有对某一对象的引用，赋值复制该引用，因此源与目标此后指代同一个对象。每个引用类型都接受`null`——指代无对象的引用（§4.8）。

`string`是具有不可变值语义的基本类型：它的值是文本字节的句柄，赋值复制句柄，但不可变性使这种共享不可观察（§4.3）。

两个类型在下列情况下是*同一类型*：

- 它们是同一个基本类型；
- 它们是数组类型，元素类型相同且秩相同；
- 它们命名同一个类型声明——不同裸池中同一名字的两个声明是不同的类型（§3.7）；
- 它们是同一个泛型容器的实例化，且类型实参两两同一。

类型别名（§3.4）是类型的另一个名字，而非自身的类型：本章每条规则都适用于被别名的类型。

### 逐类型说明

- **12个标量基本类型**（整型家族、`float`/`double`、`bool`、`char`）—— 值类型。赋值、传参、返回都按值；数值家族适用算术提升与转换矩阵（见§4.4）。见[基本类型](primitives.md)。
- **`string`** —— 经不可变驻留对象实现*值*语义：句柄被拷贝，但对象内容永不改变，所以共享句柄无害。`==`比较内容而非身份。null字符串句柄（0）读作空串`""`。见[字符串](string.md)。
- **`enum`** —— 以int32为底层类型的值类型。按值赋值、传参、返回；按整数值比较；没有独立对象身份。见[枚举](../../language-spec/enum.md)。
- **`struct`** —— 具有**深拷贝**语义的值类型：拷贝时复制整个聚合，包括嵌套struct字段。唯一例外是struct内class类型字段，浅拷贝（共享引用）。见[结构体](../../language-spec/struct.md)。
- **class** —— 引用类型。赋值/传参/返回拷贝引用（引用即对象在堆上的编号）；两个名字指向同一对象。null引用在成员访问时抛`NullPointerException`。见[类](../../language-spec/class.md)。
- **`interface`** —— 与class类似的引用类型；接口类型的值指向实现对象。见[接口](../../language-spec/interface.md)。
- **`T[]`** —— 引用类型：数组在堆上；赋值与传参拷贝数组*引用*而非元素。见[数组](../../language-spec/array.md)。
- **`List<T>` / `Dict<K,V>`** —— 引用类型；赋值与传参拷贝容器引用。见[内建泛型类](../../language-spec/builtin-generic-classes.md)。
- **`Object`** —— 可持有装箱基本类型或class引用的引用类型；赋值拷贝引用。见[Object与装箱](../../language-spec/object.md)。
- **`func`** —— 引用类型：一等函数值是堆句柄；赋值拷贝引用，`==`比较句柄所指的函数；调用null函数值抛null引用错误。见[函数](../../language-spec/functions.md)。

### 为什么分两族

分界是值vs引用：

- **值类型**（12个标量基本类型、`enum`、`string`、`struct`）在赋值时拷贝。两个变量持有独立数据；修改一个绝不影响另一个。（`string`虽是对象却属值类型，因为对象不可变。）
- **引用类型**（`class`、`interface`、数组、`List`、`Dict`、`Object`、`func`）共享底层对象。赋值拷贝引用，因此两个名字观察同一对象、同一份改动。

引用族共享一条规则：**null引用抛`NullPointerException`**——成员访问时（class、接口、数组、容器的null行为一致），以及调用null函数值时。null语义见[类](../../language-spec/class.md)。

## 4.4 赋值相容性与隐式转换

当下列规则之一适用时，值*可赋值*给某类型。该关系管辖变量初始化、赋值、实参传递与返回值转换；§15.1对包函数调用的实参传递另加限制。

- 值的类型是同一类型（§4.1）。
- 值的类型是类，目标是该类、某个祖先类，或该类实现的某个接口（隐式向上转型，§4.8与§4.9）。
- 值是标量基本类型、`string`或枚举，目标是`Object`（装箱，§4.11）。
- 目标是`string`，值是标量基本类型、枚举、类、数组或函数；该转换把值渲染为文本，渲染方式由第5章固定。
- 值是整数类型，且目标的值域包含源的值域：沿同一符号加宽（`byte`→`short`→`int`→`long`，`ubyte`→`ushort`→`uint`→`ulong`），或跨符号包含（`ubyte`到`short`、`int`或`long`；`ushort`到`int`或`long`；`uint`到`long`）。
- 值是整数类型，目标是`float`或`double`；当这一对可能丢失精度时，该转换MAY发出警告。
- 值是`float`，目标是`double`。
- 值是枚举、目标是`int`，或值是`int`、目标是枚举（§4.6）。
- 值是`null`字面量，目标是引用类型或`string`。没有其他整数隐式转换到引用类型。
- 值是整数字面量，其值落在目标整数类型的值域内——即使这两个类型之间的一般转换只能显式进行；装不下的字面量是编译期错误。只有字面量走这条规则：源类型的表达式不走，即使它折叠为常量。
- 值是`double`字面量且可被`float`精确表示，目标是`float`；浮点字面量永不隐式可赋值给整数类型。

其他一切转换在隐式流中被拒绝：即编译期错误。特别是：

- 整数收窄，以及上述包含清单之外的跨符号对；
- `float`或`double`到任何整数；
- `char`与任何数值类型之间的互转；
- `bool`到除`string`与`Object`之外的任何类型，以及任何类型到`bool`；
- `string`到除`string`与`Object`之外的任何类型；
- `Object`到类（向下转型），以及`Object`到标量基本类型或`string`（拆箱）；
- 结构体到其他任何类型，包括`Object`与`string`；
- 接口值到其他任何类型；
- 数组到其他任何数组类型或到`Object`；
- 函数值到`Object`；
- 一个泛型实例化到另一个不同的实例化。

`as`运算符执行显式转换——收窄、`char`转换、向下转型与拆箱——§4.5与§5.5定义了它。

### 数值转换矩阵

*资料性：*把上文的档位按转换方向重排。数值类型之间的转换分三档：**隐式**（编译器自动插入）、**有损警告**（隐式但警告）、**显式`as`**（用户明示，不警告）。示例见[基本类型](primitives.md)与[类型强制转换](casts.md)。

**隐式（无警告）**：

- 同符号秩加宽：`byte→short→int→long`；`ubyte→ushort→uint→ulong`。
- 跨符号值域包含：`ubyte→short/int/long`；`ushort→int/long`；`uint→long`。
- 整型→浮点且目标能精确表示该值域：窄整型（byte..ushort）→ `float/double`、`int/uint` → 仅`double`。
- 浮点加宽：`float→double`。
- `char→string`（编码为该码点的Unicode转换格式（UTF-8，Unicode Transformation Format）串）；`enum→int`（底层int值）。

**隐式但有损警告**——目标类型装不下源值域时，编译器发出`implicit conversion from 'X' to 'Y' loses precision`（`ncc --no-warn`抑制这一族警告）：

- `int/uint/long/ulong → float`
- `long/ulong → double`

常量操作数的值精确可表示时豁免（`float f = 5;`无警告）——警告指向「本次转换的实际损失」而非「类型对的可能损失」。

**常量适配特例**：整型**字面量**赋给更窄目标，值在目标值域内即隐式合法（`byte b = 5;`）；只覆盖字面量本身，不覆盖常量算术表达式（`byte b = 1 + 2;`仍需`as`）。double字面量到`float`目标同例。见[基本类型](primitives.md)。

**显式`as`**：一切收窄（`float→int`、`double→float`、`long→int`、`ulong→long`…）、反向跨符号（`short→ubyte`…）、`数值↔char`。见[类型强制转换](casts.md)。

**禁止**：`bool`与任何数值类型互转——bool只到`string`（强制转换）与`Object`（装箱），别无他处——以及`string→数值`的`as`（用`toInt()`家族）。

**算术提升**：窄于int的整型操作数先提升到int；结果类型是能同时隐式接收两个操作数的最小类型（`int + uint` → `long`；`int`/`long`与`ulong`混合是编译错误）；浮点参与取较大浮秩。bool与char不参与算术。见[运算符](../../language-spec/operators.md)。

## 4.6 枚举

枚举是用`enum`声明的一个独特类型（§2.4）。它有一组固定的命名*成员*，每个成员有一个非负整数值：显式给出的值，或比前一个成员大一（从0起算）。

枚举的表示是`int`：该类型的值可以是任意`int`，不限于已声明的成员。默认值是0。枚举与`int`之间可隐式互转（§4.4），并以整数值装箱进入`Object`（§4.11）。

对枚举值调用`toString()`返回携带该值的成员的名字。落在成员表内但没有任何成员携带的值返回空串；超出表的值在`toString()`处抛出宿主级执行期错误（第9章区分宿主级错误与异常）。

枚举可以声明方法；成员面在第8章定义。

## 4.7 结构体

结构体是用`struct`声明的值类型（§2.4）。它的成员是字段与构造器；结构体的每个字段都是public。

字段可以声明初始化器。结构体的默认值是各字段的默认值：有声明的初始化器时用初始化器，否则用该类型的默认值。

结构体可以声明构造器。构造器只在显式构造时运行——`T(args)`或`T x(args)`；裸声明与花括号初始化器列表填充字段而不运行任何构造器（第6章与第8章）。

结构体值之间的赋值复制整个值：每个字段都被复制。引用类型的字段复制其引用，因此两个结构体值此后共享那个对象（第10章）。

花括号初始化器列表按名字或按位置填充字段；被省略的字段保持其默认值（第5章）。

## 4.8 类

类是用`class`声明的引用类型（§2.4）。类类型的值是对该类一个实例的引用，或`null`。默认值是`null`。

类是单继承：至多一个父类，在声明中命名（第8章）。每个类最终都根植于`Object`（§4.11）。

两个类引用按身份比较：当且仅当两者指代同一实例或同为`null`时`==`成立。方法`equals`是另一个独立的、需显式参与的操作（第8章）。

经由`null`引用访问成员或调用方法时，是执行期错误；错误以`NullPointerException`抛出（第9章）。

构造分配一个新实例并运行该类自身的构造器；继承的字段取其默认值，除非构造器链接到某个父构造器（第8章）。

## 4.9 接口

接口是用`interface`声明的引用类型（§2.4）。它声明实例方法签名与常量声明；成员面在第8章定义。

接口类型的值是实现该接口的类的某个实例的引用，或`null`。一个类通过在声明中列出接口来实现它（第8章）；经由接口值的调用分派到该实例的重写方法（第8章）。默认值是`null`。

接口类型独立于其他一切类型：它只接受实现它的类的引用与`null`字面量，且它的值不隐式转换到任何东西——既不转换到`Object`，也不转换到另一个接口（§4.4）。

## 4.10 数组

数组类型由其*元素类型*与*秩*确定：秩是维数，至少1、至多64。秩是类型的一部分：`int[]`与`int[,,]`是不同的类型，`int[]`与`long[]`也是。秩超过64是编译期错误。

秩写作元素类型之后的单个括号后缀组（§2.3）：`[]`是秩1，`[,]`是秩2，`[,,]`是秩3，依此类推——秩是逗号数加一。一个类型至多携带一个括号后缀组：第二个组（如`int[][]`）是编译期错误。锯齿形形状——元素为长度不一的数组的数组——不可表达。

数组值按每个维度给出一个长度来创建，这些长度在该值的一生中永不改变。每个元素都从元素类型的默认值开始。创建长度为负，或长度之积超过100000000时，是执行期错误；错误以`IndexOutOfBoundsException`在创建处抛出（第9章）。

数组值是引用类型：赋值复制引用，两个变量此后共享同样的元素。读取一个结构体类型的元素得到所存结构体的副本，而非所存结构体本身；对该副本的字段写入不改变数组，要把结构体存回去需要对元素赋值（第10章）。

每个数组值支持三个成员：`length()`以`int`返回元素总数；`rank()`返回秩；`shape()`返回每个维度的长度。下标与迭代在第5章和第6章定义。

## 4.11 Object与装箱

`Object`是根类。每个不声明父类的类隐式从`Object`派生；把`Object`显式命名为父类是编译期错误。`Object`类型的值是任意类实例——包括`List`或`Dict`实例——的引用，或`null`。

`Object`声明协议成员`equals`、`getHashCode`与`toString`；它们的签名、重写与分派在第8章定义。

标量基本类型、`string`或枚举值进入`Object`位置时被*装箱*：值被包进一个堆对象，`Object`引用此后指代该对象。装箱在进入点——初始化、赋值或实参——隐式发生，且没有具名的包装类型。枚举按其整数值装箱。要把值读回来需要`as`运算符（第5章）。

没有其他类型有通往`Object`的路径：数组、结构体、接口与函数值不可赋值给`Object`，也不能用`as`转换到它（§4.4，第5章）。

## 4.12 泛型容器：List与Dict

`List<T>`与`Dict<K, V>`是内建泛型类。它们是语言中仅有的泛型类型：用户声明的类不能带类型实参。

每个实例化都是一个不同的类型（§4.1）：`List<int>`与`List<string>`不同且互不兼容，`Dict<string, int>`与`Dict<string, long>`亦然。

两者都是引用类型：值是实例的引用，默认值是`null`，实例可赋值给`Object`（§4.11）。

`List`是元素的有序序列，具有添加、读取、替换、移除与查找的操作（第13章）。`Dict`把键映射到值，具有存取、读取、测试、移除与计数的操作（第13章）；对映射中不存在的键读取值会抛出`Exception`（第9章）。

`Dict`的键相等性区分种类：基本类型的键按值比较，`NaN`不等于自身；`string`键按内容比较；类、结构体与数组的键按身份比较。对`Dict`的迭代遍历其键（第6章）。

*资料性：*两个容器的运行时表示擦除类型实参；静态类型只管辖编译期检查。

## 4.13 函数类型

函数类型写作`func<R, P1, ..., Pn>`：第一个类型实参是返回类型——函数不返回值时为`void`——其余实参按顺序是参数类型（§2.3）。参数类型实参可以携带`out`前缀。无参数的函数写作`func<R>`。

`void`只作为`func<...>`返回槽的类型实参出现；任何其他写作`void`的类型实参——如`List<void>`——都是编译期错误。

两个函数类型是同一类型，当且仅当它们的返回类型、参数类型与`out`标记逐位置一致。没有变异性：返回类型与参数类型都不允许不同，即使差异只是一次隐式转换也不行（§4.4）。

函数类型的值指代一个函数：自由函数、静态方法，或绑定到某个实例的方法（第7章）。默认值是`null`；调用`null`函数值是执行期错误。函数值是引用类型，其唯一的隐式转换是到`string`（§4.4）：它不进入`Object`。
