# 4.10 数组

## 4.10.1 元素类型与秩

数组类型由其*元素类型*与——写方括号时——*秩*确定：秩是维数，至少1、至多64。方括号拼写之间秩是类型的一部分：`int[]`与`int[,,]`是不同的类型，`int[]`与`long[]`也是。秩超过64是编译期错误。

秩写作元素类型之后的单个括号后缀组（§2.3）：`[]`是秩1，`[,]`是秩2，`[,,]`是秩3，依此类推——秩是逗号数加一。一个类型至多携带一个括号后缀组：第二个组（如`int[][]`）是编译期错误。锯齿形形状——元素为长度不一的数组的数组——不可表达。

每个数组值的类型都是标准库的泛型类`Array<T>`：方括号拼写是这一个类型的*标注*形式，`int[]`与`Array<int>`在每个编译期检查中都是同一类型——赋值、传参、重载决议、容器元素。标注是编译器兑现的承诺（坐标数编译期检查、`rank()`折叠为常量、下标直接发射）；不带方括号的`Array<int>`拼写不作秩承诺，秩此时活在值里（§4.10.7）。把元素写成类型实参同样触发锯齿拒绝：`Array<Array<int>>`就是`int[][]`，是编译期错误；装数组引用的容器——`List<Array<int>>`、`Array<List<int>>`——仍然合法（§4.12.5）。

## 4.10.2 创建

数组值按每个维度给出一个长度来创建，这些长度在该值的一生中永不改变。每个元素都从元素类型的默认值开始。每个创建维度都是整数表达式——字面量、变量、调用结果，任何值为整数的表达式；枚举成员按其整数值参与，值为浮点的维度是编译期错误。创建长度为负，或长度之积超过100000000时，是执行期错误；错误以`IndexOutOfBoundsException`在创建处抛出（第8章）。

秩本身是执行期事实的值经泛型拼写创建：目标类型确定元素类型，维度由秩1的`int[]`给出，其长度即秩。

```nlang
int[] dims = int[2];
dims[0] = 2; dims[1] = 3;
Array<int> m = Array(dims);   // 秩2，2x3，零填充
Array<float> w = Array(dims); // 元素类型来自目标
```

秩——`dims`的长度——必须在合法范围内（1到64），在值创建时校验；长度为0或超过64抛出可捕获的`IndexOutOfBoundsException`。`dims`实参必须是秩1的`int`数组：其他元素类型是编译期错误。

```nlang
int[] a = int[3];         // 表达式位：定长创建，元素零初始化
int[] b = [1, 2, 3];      // 裸方括号字面量
int[] e = [];             // 空数组字面量（int[0]等价）

int d[3];                 // 声明位定长：零填充
int f[100] = [7, 8];      // 声明位部分初始化：余位零填充
```

- 在**表达式位**，`int[3]`创建数组，`[1, 2, 3]`是集合字面量形式；花括号形式`{...}`保留给集合、结构体与类初始化器，对数组目标被拒绝（§4.10.8）。
- 在**声明位**，`int d[3];`直接声明定长数组；带初始化器时，未列出的元素保持默认值。逗号分隔列表的每个声明符都可自带尺寸（§3.8）。
- 只声明不初始化（`int[] g;`）得到`null`（§3.8）。
- 元素类型可以是结构体（每个元素是一份独立的值，§4.7.4）或类（存储引用，§4.8.1）。

## 4.10.3 引用语义

数组值是引用类型：赋值复制引用，两个变量此后共享同样的元素。被调方经传入数组做的元素写入对调用方可见；数组字段或元素存储的是引用。

读取一个结构体类型的元素得到所存结构体的副本，而非所存结构体本身；对该副本的字段写入不改变数组，要把结构体存回去需要对元素赋值（§4.7.4，第9章）。

数组值同时也是`Object`（§4.11）：两种拼写流入`Object`位都不产生分配，协议调用`toString`、`equals`、`getHashCode`到达数组自己的实现——`toString`渲染元素列表（`"[7, 0, 0, 0]"`），另两个按身份比较（§4.11.2）。

## 4.10.4 成员：length、rank、shape

每个数组值支持三个成员：`length()`以`int`返回元素总数；`rank()`返回秩；`shape()`返回每个维度的长度。它们是方法，无参数，与`string.length()`形态一致（§4.3）。

*资料性：*数组成员方法（`length`、`rank`、`shape`、`toString`、`equals`、`getHashCode`）由标准库`lang`包中的泛型面类`Array<T>`声明。这个类只为持有声明而存在——不能被继承（泛型实例化不是合法的父类，§4.12）——但与`String`不同，它是真实的类型：`Array<int>`可用于一切类型位，其值经`Array(dims)`或§4.10.2的方括号创建形式构造。不带类型实参的裸名`Array`仍是编译期错误。

## 4.10.5 下标

`a[i]`读写元素；索引是整数表达式。下标还可以携带切片条目，产生视图——见§4.10.9。

```nlang
int[] a = int[3];
a[0] = 9;
a[1] = a[0] + 1;
int x = a[a.length() - 1];
```

下标左值接受复合赋值（`a[i] += 1`），规则与其他左值相同（第5章）；对结构体元素，写入落在数组自己的元素上（§4.10.3）。

方括号标注的数组，坐标数是编译期检查（§4.10.7）。类型为不带方括号的`Array<T>`的值，源码仍写定坐标数，坐标数在下标执行时与值的秩比对：不符抛出可捕获的`IndexOutOfBoundsException`，消息同时给出两个数目。没有坐标数组的分配——检查就在同一次下标操作里。

```nlang
int[] dims = int[2];
dims[0] = 2; dims[1] = 3;
Array<int> m = Array(dims);           // 秩2
m[1, 2] = 9;                          // 两个坐标，秩2：正常
int v = m[0];                         // 执行期错误：1个坐标对秩2
```

## 4.10.6 越界

索引落在`0`到该维长度减一之外时，读与写都是可在执行期捕获的错误，以`IndexOutOfBoundsException`抛出（第8章）。

*资料性：*§4.10.2的创建上限覆盖所有创建路径——`T[n]`与tensor包的native铸造一视同仁；最宽元素下1亿个元素为800MB。

## 4.10.7 多维数组

矩形多维数组写作`T[,]`（二维）、`T[,,]`（三维），至多秩64（§4.10.1）。维度数是类型的一部分：`int[,]`与`int[]`是两个无关的类型，互相赋值、互传形参都是编译期错误。

```nlang
int[,] grid = int[2, 3];      // 2x3，元素零初始化
grid[1, 2] = 7;               // 逗号下标读写
int rows = 2;
int[,,] t = int[rows, 1, 2];  // 尺寸可以是表达式，运行期判定
```

- `a[i, j]`的坐标数必须与秩相等——坐标多了或少了都是编译期错误——且每个坐标是整数表达式；坐标越界以`IndexOutOfBoundsException`抛出，与秩1情形完全相同（§4.10.6）。（不带方括号的`Array<T>`值，坐标数是执行期检查，§4.10.5。）
- `a.rank()`返回秩；`a.shape()`返回秩1的`int`数组，携带每个维度的长度；`a.length()`返回元素总数，即各维之积（§4.10.4）。
- `foreach`按行主序迭代元素，最后一维变化最快；循环变量类型是元素类型（第6章）。
- 数组类型可作形参、返回类型、字段与容器元素类型，且跨模块导入原样存活；引用语义与`string`目标规则与秩1情形一致（§4.10.3）。

声明位尺寸只支持秩1（`int b[100]`）；多维数组用创建形式——`int a[2, 3];`是编译期错误。

### 标注拼写与无括号拼写之间的流动

带方括号的值流入无括号的`Array<T>`位完全自由——标注说的是更多信息，不是别的信息。反方向携带值尚未给出的承诺，编译器插入隐式的*边界秩检查*——在赋值、传参、返回的每个边界各检查一次，而非每次访问都查。值的秩与标注不符时，检查抛出可捕获的`InvalidCastException`，消息写明预期秩与实际秩；`null`按`null`通过（§4.5）。同一检查的显式形式是转型`a as int[,]`（§4.5）。

```nlang
int[,] grid = int[2, 3];
Array<int> dyn = grid;        // 标注 -> 无括号：自由
int[] row = dyn;              // 边界检查：秩2对秩1，抛出
int[,] back = dyn as int[,];  // 同一检查的显式形式
```

两个方括号拼写之间的不符（`int[]`流入`int[,]`）仍是编译期错误：两边都已作出承诺。

## 4.10.8 初始化器

数组初始化器是方括号字面量。秩1目标下条目是元素表达式；更高秩下字面量按目标的维度数逐层嵌套，且形状在编译期校验为矩形：嵌套深度等于维度数，每层内各行等宽。元素按行主序落入新数组。

```nlang
int[,] m = [[1, 2], [3, 4]];
int[,,] t = [[[1, 2]], [[3, 4]]];
double half = 0.5;
double[,] w = [[half, half * 2], [0.0, 1.0]];   // 元素可以是表达式
```

锯齿形字面量——每层内行宽不等——以及嵌套深度与维度数不符，都是编译期拒绝。维度数为2及以上时字面量必须非空：没有行就没有可推断的维度（秩1的`int[] a = [];`形式仍然合法）。

叶子层之上的条目还可以是一个值恰比目标低一维的数组的表达式——函数结果、变量、任何数组值表达式——且这类表达式行可与同层的方括号行自由混排。

```nlang
int[] makeRow(int w) {
    int[] r = int[w];
    for (int i = 0; i < w; i += 1) { r[i] = i; }
    return r;
}

int[,] m = [makeRow(2), [3, 4]];    // 表达式行＋方括号行
```

有表达式行时，形状是执行期事实：第一行钉住内层维度，后续每一行都必须与它一致。宽度不同的行抛出可捕获的基类`Exception`，点名所在层与两个宽度；`null`行抛出`NullPointerException`（第8章）。没有表达式行时，整个形状仍是编译期事实。

花括号形式`{...}`不被数组目标接受。

*资料性：*完整的初始化器列表规则——包括字面量可以瞄准的目标形状——见[集合初始化器](../05-expressions/initializers.md)。

## 4.10.9 切片与视图

下标可以在普通索引的位置携带*切片条目*：每个轴上写`start:stop:step`，三部分都可省略（§2.4）。结果不是副本而是*视图*——一个新的数组值，其元素是源数组在所选位置上的元素。

```nlang
int[,] m = int[4, 4];
int[,] tl = m[0:2, 0:2];      // 2x2左上角
int[] row = m[1, :];          // 普通索引降掉所在轴：秩1
int[] rev = m[0, ::-1];       // 步长-1沿轴倒着走
```

结果的秩是切片轴的数目：普通索引沿所在轴选定一个位置并把它从形状中除去，切片条目保留自己的轴、长度为所选数目。秩1数组切片（`a[1:3]`）得到秩1视图；全索引下标（`m[0, 1]`）就是§4.10.5的元素访问，不产生视图。

每个切片轴按Python风格独立归一化。省略的端点按步长符号取默认值——正步长取`0`与轴长，负步长取末位与首位之前。负端点从末尾数起（`-1`是末位）；端点按轴裁剪；步长为`0`是执行期错误，以可捕获的基类`Exception`抛出（§8.3）。空选取合法，得到该轴长度为`0`的视图。

视图是元素类型同源数组的普通数组值：赋值复制视图引用，§4.10.4的成员报告视图自己的形状与数目，`toString`渲染所选元素，§4.10.7的流动规则原样适用。让它成为视图的是*别名*：元素读写直达源数组——

```nlang
int[] a = [1, 2, 3, 4];
int[] mid = a[1:3];
mid[0] = 9;                   // 写入a[1]
a[2] = 7;                     // 经mid[1]可见
```

——视图的视图可复合：对视图切片寻址的是原始元素，不是副本的副本。切片表达式本身不能作赋值目标（`a[1:3] = x`是编译期错误）：视图是值，存储经它自己的下标逐元素进行。

经广播视图（`broadcastTo`，§18.2）或对已广播的轴再切片，一个轴可以把多个视图位置映射到源的同一位置。读取时重复读该源元素；这样的轴只要跨多于一个位置，存储就被拒绝——两个逻辑单元指向一个源单元会静默吞掉一次写入——以可捕获的基类`Exception`点名该轴。长度为1的轴不论步长都只寻址一个源位置，单元素切片与尺寸1的广播轴因此保持可写；负步长轴没有这种别名，同样保持可写。

*资料性：*视图的实现是记录的形状、逐轴步长与源元素中的偏移；一个切片视图在某轴上的长度不依赖其他轴。经`writeObject`写视图写出的是它的*逻辑内容*——一条新记录，往返得到独立的拥有数组（§14.5）。
