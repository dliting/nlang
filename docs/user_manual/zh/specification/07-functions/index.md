# 7. 函数

函数有一个返回类型或`void`、一个名字、零个或多个形式参数，以及一个体。本章规定声明形式、参数与实参规则、重载解析、函数值与原生函数；声明的语法在顶层见§2.2，类、结构体、枚举与接口的成员见§2.4。参数与实参（§7.2）、重载解析（§7.3）、函数值与委托（§7.4）与原生函数（§7.5）各有独立页面。

## 7.1 声明形式

函数或方法声明的语法：顶层见§2.2，类、结构体、枚举与接口的成员见§2.4。声明给出返回类型或`void`、一个名字、零个或多个形式参数，以及一个体。不带返回类型的方法声明命名一个构造器（§4.8.6）。

顶层函数不带访问修饰符且不带标志时即为*裸函数*（§2.2）。这一区分纯属语法：在顶层，访问修饰符与`static`、`virtual`标志都被接受且没有效果——它们管辖类成员（§4.8）。每个顶层函数在其自身单元内都以裸名可见。跨单元时，裸可见性遵循§3.6，限定名则经导入门到达该函数（§3.6，§3.9）；两条路径都不查看修饰符。在顶层只有`native`带有含义（§7.5）。

写作`;`的体声明一个无体的函数：顶层是原生函数（§7.5），或接口中没有默认实现的成员（§4.9.2）。

`void`函数不返回值。`return;`提前退出它（§6.6）；对它的调用只用作语句——对其结果赋值、返回它，或把它用作操作数——都是编译期错误（§5.6）。`void`在任何其他位置都不是类型：`void`类型的局部、字段、参数或数组元素是语法错误。

一个函数至多声明64个形式参数；更多是声明期错误。允许递归。调用深度有界（1000帧）；超过界限抛出*宿主级*执行期错误：宿主报告错误并终止程序，且没有`catch`子句处理它（第8章）。

### 函数声明

```nlang
int add(int a, int b) {
    return a + b;
}
```

*资料性：*方法在class、struct、enum或interface内部声明，形状相同；不带返回类型的方法声明是构造器（§4.8.6）。值在参数与返回边界上会发生什么，遵循第4章的值模型：struct被复制，class、接口、数组或函数值共享其对象，返回值按同一条规则移动（§7.2、§6.6）。数组与容器同样可作返回类型（见[数组](../04-types/array.md)与[集合初始化器](../05-expressions/initializers.md)）。

### `void`函数

*资料性：*`void`适用于自由函数、类方法（任意修饰符组合，例如`public static void f()`）以及接口成员（和所有接口成员一样，缺省为`public`）。

```nlang
void log(int level) {
    if (level == 0) { return; }   // 用裸 `return;` 提前退出
}

class Counter {
    public int hits;
    public void bump(int by) { this.hits = this.hits + by; }
}
```

- 值返回函数不能使用裸`return;`（编译错误）
- void函数可与`out`参数组合，实现只有副作用的调用（§7.2）
- 跨模块：导入的`void`函数同样没有结果值；上述「结果不可使用」规则同样适用

### 栈帧布局

*资料性：*每个函数的局部帧按其函数体动态确定大小，随调用的实际需要增长；深层递归由递归深度上限（1000）约束。64个形参的合理性上限防止帧过大。
