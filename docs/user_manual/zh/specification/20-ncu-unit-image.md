# 20. `.ncu`单元映像

*单元映像*是一个包的编译产物：`ncc`写出它，每个工具的加载器读回它（§12.3）。本章固定映像的字节布局——容器、记录表、类型描述符、默认值与导入槽——以及加载器在映像运行之前执行的校验。§20.1界定范围并固定格式版本；§20.2固定容器；§20.3–§20.7定义各记录；§20.8陈述加载契约。

## 20.1 范围与版本

**格式版本。**本章描述格式版本 **2.11**，在头部中记为主`2`、次`11`（§20.2）。符合规范的加载器恰好接受这一版本，拒绝其他一切版本：较旧的映像以「重新编译」诊断拒绝，较新的映像以「升级工具链」诊断拒绝（§20.8）。没有迁移，也没有部分接受。格式变更会提升版本并整章替换本章；规范只描述当前版本。

**本章固定的内容。**容器布局（§20.2）、函数记录（§20.3）、类型记录（§20.4）、类型描述符（§20.5）、默认值与默认表达式（§20.6）、导入槽（§20.7）与加载契约（§20.8）。

**本章不固定的内容。**函数字节码数组内部指令的编码：在这里，该数组是一段不透明字节串。它被钉在同一个格式版本上——2.11的映像携带2.11工具链的指令集——但操作码值与指令形式不是本规范的一部分。原生调用约定是§22.4；打包映像的档案是第21章。

**确定性。**同一个`ncc`对同一源程序编译两次产出字节相同的映像：写出器不记录时间戳，且每张表都按声明序。

## 20.2 容器布局

**约定。**每个整数都按小端序写出，最低有效字节在前，二进制补码形式。*长度前缀字符串*是其字节数随后恰好那么多字节；没有终止符，映像也不对这些字节强加文本编码。下文的宽度表用`u8`、`u16`与`u32`表示1、2、4字节的无符号整数，`i16`表示2字节的有符号值，`f32`与`f64`表示IEEE 754 binary32与binary64编码（§4.2）。

**头部。**映像以下列内容开始：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 幻数 | 8字节 | `NLANGCU`后跟一个零字节 |
| 版本主号 | u16 | `2` |
| 版本次号 | u16 | `11` |
| 模块路径 | u16长度 + 字节 | 该单元的包路径（§12.1） |
| 名称 | u32长度 + 字节 | 单元名：当前工具链写出的每个映像中，与模块路径相同的字符串 |
| 入口键 | u16长度 + 字节 | 入口函数的限定键（§3.6）（§10.3）；库映像为空（§12.1） |

**节。**头部之后是按固定顺序排列的十一节。每节是一个u32条目数，随后是那么多条记录：

| # | 节 | 记录 |
|---|---|---|
| 1 | 字符串常量 | u32长度 + 字节 |
| 2 | 函数 | §20.3 |
| 3 | 结构体 | §20.4 |
| 4 | 类 | §20.4 |
| 5 | 接口 | §20.4 |
| 6 | 数组类型 | §20.4 |
| 7 | 枚举 | §20.4 |
| 8 | 函数导入 | §20.7 |
| 9 | 类导入 | §20.7 |
| 10 | 结构体导入 | §20.7 |
| 11 | 枚举导入 | §20.7 |

**名称。**每个函数、类、结构体、接口与枚举都以其限定键`<package>.<name>`记录，其中`<package>`是头部的模块路径（§3.6，§12.3）。外部制品在单段包路径下查找（§12.2），所以它的映像携带单段模块路径。

**字符串常量。**池中存放该单元的字符串字面量；字节码与§20.6的默认值按索引引用它。

## 20.3 函数记录

函数节为该单元的每个函数、方法与构造器存放一条记录，按注册序。每条记录：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 名称 | u32长度 + 字节 | 限定键（§3.6） |
| 帧大小 | u16 | 以字节计的帧大小，每槽八字节：参数（含接收者）、局部量与暂存槽（§10.2） |
| 参数数 | u16 | 形参数，含方法或构造器的隐式接收者槽（§8.1） |
| 返回种类 | u16 | 返回类型的类型种类码（§20.5）；`void`为`0xFE` |
| 固有函数id | u16 | 普通函数为`0xFFFF`；否则为内建固有函数的引擎内部标识符 |
| native旗标 | u8 | 无函数体的`native`声明为`1`（§7.5） |
| static旗标 | u8 | 静态成员为`1`（§8.1） |
| 默认值数 | u16 | 随后是那么多条默认值记录（§20.6） |
| 字节码大小 | u32 | 随后是那么多字节指令 |
| try块数 | u16 | 随后每个条目五个u16值 |
| 局部量数 | u16 | 随后每个条目一个局部量描述符 |
| 源文件 | u32长度 + 字节 | 该函数编译自的源路径 |
| 参数描述符数 | u16 | 随后每个条目一个参数描述符 |
| 返回描述符 | u16长度 + 描述符 | 返回类型描述符（§20.5）；仅当返回种类不是`0xFE`时存在 |
| 句柄掩码大小 | u32 | 随后是那么多字节掩码 |

**默认值。**默认值数是每个已写形参一个条目：自由函数等于参数数；方法或构造器少一个，因为接收者不带默认值（§7.2）。

**字节码。**指令数组在这里是不透明的（§20.1）。`native`记录携带空数组：按契约该声明没有函数体（§7.5）。

**try块。**每个条目是五个2字节值：受保护范围的起始与结束字节码偏移、处理入口偏移、被捕获类型的类表索引，以及接收异常的局部量的帧字节偏移（§9.2）。

**局部量描述符。**每个条目是帧字节偏移（u16）、字节大小（u16）、参数旗标（u8，形参或接收者为`1`）、声明类型的种类码（u8，§20.5）、该局部量变为可见的字节码偏移（u16；入口处为`0`——参数与接收者），以及名称（u32长度 + 字节）。

**参数描述符。**每个已写形参一个——方法的接收者不被描述：一个旗标字节（bit `0`置位标记`out`参数，§7.2），随后是一个长度前缀类型描述符（§20.5）。

**句柄掩码。**尾部字段告诉垃圾回收器要追踪哪些帧槽（§10.2）。它覆盖从第一个局部量——索引等于参数数——到最后一个帧槽的槽位。每个槽携带一个2位码：`0`不持有根，`1`字符串句柄，`2`堆索引（类、结构体或数组实例），`3`两者之一；四个槽共用一个字节，编号最低的槽在最低的两个比特位。大小是带内槽数除以四、向上取整；带为空的记录——`native`或固有函数记录——写大小`0`。

## 20.4 类型记录

**访问字节。**成员的声明访问级别是一个字节：`0`默认，`1` `private`，`2` `protected`，`3` `public`（§8.1）。

**结构体。**每个结构体一条记录，按声明序：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 名称 | u32长度 + 字节 | 限定键（§3.6） |
| 字段数 | u16 | |
| 字段名 | 每个u32长度 + 字节 | 声明序 |
| 字段种类 | 每个u16 | 字段类型的种类码（§20.5） |
| 字段结构体索引 | 每个u16 | 结构体类型字段的结构体表索引；否则`0xFFFF` |
| 字段类索引 | 每个u16 | 类类型字段的类表索引；否则`0xFFFF` |
| 字段描述符 | 每个u16长度 + 描述符 | §20.5 |
| 构造器数 | u16 | 随后是那么多u16函数表索引，声明序 |
| 字段默认值数 | u16 | 等于字段数；随后每个字段一条默认值记录（§20.6） |
| 构造器访问 | 每个u8 | |

*无默认值*（§20.6）的字段默认值让字段保持其类型的零值；其余默认值在每次分配时施加（§8.5）。

**类。**每个类一条记录，按声明序：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 名称 | u32长度 + 字节 | 限定键（§3.6） |
| 字段数 | u16 | 本类声明的字段 |
| 超类索引 | i16 | 超类的类表索引；无则为`-1` |
| 字段名 | 每个u32长度 + 字节 | |
| 字段种类 | 每个u16 | |
| 字段结构体索引 | 每个u16 | |
| 字段类索引 | 每个u16 | |
| 字段描述符 | 每个u16长度 + 描述符 | |
| 字段访问 | 每个u8 | |
| 方法数 | u16 | 随后是那么多u16函数表索引：本类声明的每个成员，静态与实例，声明序 |
| 方法访问 | 每个u8 | |
| 方法虚旗标 | 每个u8 | `virtual`方法为`1`（§8.2） |
| 构造器数 | u16 | 随后是那么多u16函数表索引 |
| 构造器访问 | 每个u8 | |

字段表只携带本类声明的字段：完整实例布局在加载时沿超类链从基类先行走一遍导出（§8.1）。构造器也出现在方法表中；构造器表把它们选出来。

**接口。**每个接口一条记录，按声明序：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 名称 | u16长度 + 字节 | 限定键（§3.6） |
| 静态方法数 | u16 | 随后是那么多u16函数表索引 |
| 常量数 | u16 | 每个条目：u16长度的名称、一个长度前缀类型描述符与一条默认值记录（§20.6） |
| 签名数 | u16 | 每个条目：u16长度的名称、一个u16参数数、每个形参一个旗标字节与一个长度前缀类型描述符、一个长度前缀返回描述符，以及一个u16默认值数随后是那么多条默认值记录 |

接口常量是标量或字符串（§8.3）；其默认值记录携带折叠后的初始化器。实例方法签名让消费方在导入的接口类型接收者上解析调用，并跨包边界检查`implements`契约（§8.3）。返回描述符总是存在：`void`是`0xFE`种类字节。接口成员隐式公共且非虚，所以不记录访问或虚字节。

**数组类型。**该单元使用的每个不同数组类型一条记录：元素种类（u8，§20.5）、元素类型索引（u16；基本类型元素为`0xFFFF`），以及秩（u8，§4.3）。

**枚举。**枚举节是三张平行表，每个枚举一行，按声明序。先是成员值：一个u32计数，随后是每个值名（u32长度 + 字节）。然后是限定键：每个枚举一个（u16长度 + 字节），没有单独的计数。最后是成员方法：一个u32计数，随后每个方法一个u16函数表索引与一个访问字节（§8.4）。

## 20.5 类型描述符

*类型描述符*是一个声明类型的递归编码。描述符出现在字段描述符、参数描述符、返回描述符、接口常量类型与接口实例方法签名中（§20.3，§20.4）。在字节流上，一个描述符是一个u16字节数，随后是那么多字节描述符；计数`0`记录一个在此文法中不可表达的类型，为这样的成员重建桩的消费方退化到`int`占位类型。

描述符字节是一个种类码随后一个载荷：

| 种类 | 类型 | 载荷 |
|---|---|---|
| `0` | `int` | 无 |
| `1` | `float` | 无 |
| `2` | `string` | 无 |
| `3` | 结构体 | u16结构体表索引 |
| `4` | 类 | u16类表索引 |
| `5` | 数组 | 一个嵌套元素描述符，然后一个秩字节（§4.3） |
| `6` | 装箱基本类型 | 无（§4.9） |
| `7` | 函数值 | 一个参数计数字节，然后是count+1个嵌套描述符：各参数，然后返回类型（`void`为`0xFE`）（§4.11） |
| `8` | `List` | 一个嵌套元素描述符（§4.10） |
| `9` | `Dict` | 两个嵌套描述符：键类型，然后值类型（§4.10） |
| `10`–`19` | `byte` `ubyte` `short` `ushort` `uint` `long` `ulong` `double` `bool` `char` | 无 |
| `0xFB` | 不可序列化 | 无 |
| `0xFE` | `void` | 无 |

**上限。**描述符至多嵌套8层、至多跨4096字节；参数描述符表至多携带256个条目。描述符会超出嵌套或大小上限的容器，写出器把它记为*不可序列化*；读取器拒绝超出任一上限的描述符。

## 20.6 默认值与默认表达式

*默认值记录*是固定布局的记录：每个通道总是存在，标记选出其中有意义的那一个。它作为形参的默认值（§20.3）、结构体字段的默认值（§20.4）与接口常量的值（§20.4）出现。

| 字段 | 宽度 |
|---|---|
| 标记 | u8 |
| int通道 | u32 |
| float通道 | f32 |
| 字符串索引 | u32 |
| long通道 | i64 |
| double通道 | f64 |
| 表达式长度 | u16，随后是那么多字节表达式 |

| 标记 | 含义 |
|---|---|
| `0xFE` | 无默认值 |
| `0xFD` | `null`字面量，用于任何引用类型 |
| `0` | int通道中的一个`int`；也用于`bool`（`0`或`1`）与`char`（码点） |
| `1` | float通道中的一个`float` |
| `2` | 一个`string`：字符串索引命名产出方的字符串常量池（§20.2）；导入合并把它重映射进消费方的池（§20.7） |
| `15` / `16` | long通道中的一个`long`或`ulong`（`ulong`的位模式） |
| `17` | double通道中的一个`double` |
| `0xFB` | 默认表达式：表达式字节承载下文的树 |
| `0xFC` | 可表达子集之外的默认值：必须把它实体化的消费方报告错误 |

结构体字段默认值与接口常量只携带可折叠的标记——从不`0xFB`或`0xFC`（§4.6，§8.3）。

**默认表达式。**可折叠子集之外的默认值搭载一棵小表达式树；每个节点以一个标记字节开始：

| 标记 | 内容 |
|---|---|
| `0` `1` `15` `16` `17` | 匹配通道宽度的标量字面量：`int`与`float`为4字节，`long`、`ulong`与`double`为8字节 |
| `2` | 一个字符串：u32字符串常量索引（产出方池） |
| `0xFD` | `null` |
| `0x20` | 引用同一函数的较早形参：u8形参索引（§7.2） |
| `0x21` | 一元取负，然后一棵子树 |
| `0x22` | 二元表达式：一个运算符字节（`0` `+`、`1` `-`、`2` `*`、`3` `/`、`4` `%`、`5` `<<`、`6` `>>`），然后两棵子树 |
| `0x23` | 一次调用：u16长度与被调方的限定键、一个u32参数数、一个u8实参数，然后是那么多个子树 |

默认表达式树至多嵌套16层、至多跨4096字节；表达式会超出任一上限的默认值，写出器把它记为`0xFC`，读取器拒绝超出任一上限的树。

## 20.7 导入槽

对另一个包中声明的引用，记为一个*导入槽*追加到它所属的表上：表自身的条目占据索引`0..n-1`，其导入占据`n..n+m`，所以对外部声明的编译期引用是高于自身条目数的表索引。四个导入节遵循§20.2的表顺序。

每个条目：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 模块路径 | u16长度 + 字节 | 目标包路径（§12.1） |
| 名称 | u16长度 + 字节 | 限定键（§3.6）；所属键置位时是裸名 |
| 参数数 | u32 | 目标的形参数；对函数槽有意义 |

函数节另加：

| 字段 | 宽度 | 内容 |
|---|---|---|
| 所属键 | u16长度 + 字节 | 包级函数为空；否则为所属类或结构体的限定键 |
| static旗标 | u8 | 链接同一性的一部分：同名同元数的静态成员与实例成员是不同的槽 |
| 所属种类 | u8 | `0`包级，`1`类成员，`2`结构体成员 |
| 所属序数 | u16 | 成员在所属表中的位置：构造器为构造器表索引；否则为方法表位置、跳过构造器条目；包级函数为`0xFFFF` |

重载成员共享名称与参数数，所以所属序数唯一选定目标。加载器通过加载目标包并定位成员来绑定每个槽（§12.3）。

## 20.8 加载与校验

加载器严格读取映像并整体拒绝它：被拒绝的映像绝不会部分运行。拒绝位点：

- **幻数。**除幻数以外的头部字节 → 拒绝。
- **截断。**在记录中途结束的流 → 拒绝。
- **版本。**低于2.11 → 以「用当前编译器重新编译」诊断拒绝；高于2.11 → 以「升级工具链」诊断拒绝（§20.1）。
- **计数与长度上限。**计数与长度在分配之前设界。上限2^24：单元名、字符串常量数与每个常量的长度、数组类型数、函数/结构体与类的计数及其名称与字段名长度、枚举数、枚举值数与每个值名长度，以及每个导入节的计数。上限2^20：接口数与枚举成员方法数。上限2^16：局部量名、源文件路径与句柄掩码字节。更大的值在分配之前拒绝。
- **描述符索引。**类型表读完后，类型描述符携带的每个结构体与类索引——在函数参数与返回描述符、字段描述符、接口常量类型与接口实例方法签名中——必须指向一个存在的表条目。
- **所属种类。**所属种类高于`2`的导入槽 → 拒绝。
- **导入尾部。**大于其表自身条目数的导入计数 → 拒绝。
- **句柄掩码。**不同于§20.3带大小的掩码字节数——帧槽数（帧大小除以八）减去参数数，每四个槽一个码、向上取整；空带为零—— → 拒绝。
- **入口键。**空键意味着无入口（库映像）；非空键必须命名映像的一个函数，否则拒绝映像。

被拒绝的映像表现为加载工具的加载期错误（§12.3）；语言不定义恢复。
