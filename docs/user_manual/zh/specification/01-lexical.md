# 1. 词法结构

## 1.1 源码编码

源文件MUST以Unicode转换格式（UTF-8）编码。文件开头的字节顺序标记（BOM）MUST被接受并忽略。不是有效UTF-8的源文本是编译期错误。

## 1.2 注释

行注释以`//`开始，在换行处结束。块注释以`/*`开始，在最先出现的`*/`处结束；块注释不嵌套，且MAY跨行。注释按空白处理：它从不构成记号，也从不把本会连成一体的记号分隔开（关于唯一一条跨注释的「名字后接`<`」规则，见§1.6）。未闭合的块注释是编译期错误。

## 1.3 标识符

标识符以字母或下划线开始，后接字母、数字或下划线。标识符限定在美国信息交换标准代码（ASCII）字符集之内，且区分大小写。标识符MUST NOT是保留字（§1.4）。

## 1.5 字面量

### 1.5.1 整数字面量

整数字面量是十进制（`0`–`9`数字）或十六进制（`0x`或`0X`前缀）。整数字面量是无符号的：前导的`-`是一元负号运算符，不是字面量的一部分。字面量的类型按值选定：不超过2147483647时为`int`；不超过9223372036854775807时为`long`；否则为`ulong`。超过18446744073709551615的值是编译期错误。

### 1.5.2 浮点字面量

浮点字面量有小数形式（数字、`.`、至少一个数字——小数点之前的数字MAY省略）或指数形式（`digits`、`e`或`E`、可选符号、数字），并且可以带`f`或`F`后缀。无后缀的浮点字面量类型为`double`；带`f`或`F`后缀的字面量类型为`float`。

### 1.5.3 字符字面量

字符字面量是单引号之间的一个Unicode标量值，或一个表示单个标量值的转义序列。转义`\n`、`\r`、`\t`、`\'`与`\\`已定义。转义`\uXXXX`表示基本多文种平面（BMP）中与该数值对应的码点；单独写出的代理码点是编译期错误。字符字面量至多容纳一个`\uXXXX`转义：代理配对（§1.5.4）不适用于字符字面量，因此没有字符字面量能经由转义表示非BMP标量值。引号之间的任何其他字符都是编译期错误。

### 1.5.4 字符串字面量

字符串字面量是双引号之间的文本。它MUST NOT包含裸换行。转义`\n`、`\r`、`\t`、`\"`、`\\`、`\'`、`\0`、`\a`、`\b`、`\f`、`\v`与`\uXXXX`已定义；任何其他转义都是编译期错误，未闭合的字符串同样是。在字符串内部，`\uXXXX`表示一个BMP码点，单独写出的代理码点是编译期错误，但相邻的高代理与低代理对（`\uD800`–`\uDBFF`后接`\uDC00`–`\uDFFF`）表示它们配对而成的那个非BMP标量值。字符串字面量作为一个记号做词法分析；字符串内的插值形式`${identifier}`在表达式层解释（第5章）。

## 1.6 运算符与标点

语法中出现的多字符运算符有：

`<<` `<<=` `>>` `>>=` `<=` `>=` `!=` `==` `&&` `||`
`%=` `*=` `+=` `-=` `/=`

词法分析器也会产生序列`++` `--` `&=` `|=` `~=`，但它们都不出现在任何产生式中，因此每一个在它出现的每一处都作为语法错误被拒绝。单字符标点自成一个记号。哪些记号序列在什么位置合法，由语法（第2章）定义。

类型实参括号：跟随内建泛型名`List`、`Dict`、`Channel`、`Future`或关键字`func`之一的`<`——二者之间只有空白或注释——MUST被读作开启一个类型实参表，而不是比较运算符。在一个已开启的类型实参表内部，`>>`与`>>=`各自关闭一层嵌套，其余部分重新扫描，因此`List<List<int>>`与`List<List<int>>=`都能解析。其他任何`<`都是比较运算符。

数组类型后缀：`[]`表示一维数组类型；`[`、一个或多个逗号、`]`表示秩等于逗号数加一的矩形数组类型（第4章）。
