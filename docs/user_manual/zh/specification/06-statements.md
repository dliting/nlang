# 6. 语句

## 6.1 块与局部声明

语句的语法见§2.5。段`{ ... }`是一条其声明具有块作用域的语句（§3.5）；段只约束可见性，被重新声明的名字的存储遵循§3.5的共享规则。

局部声明`T x;`把`x`绑定到`T`的默认值（§4）。带初始化器的声明`T x = e;`求值`e`并把值存入`x`；该值必须可赋值给`T`（§4.12）。绑定与求值都发生在声明语句处，按语句顺序（§3.5）。含多个声明符的声明逐个声明每个名字；各初始化器的求值顺序未指明（§0.4）。

`const T x = e;`要求初始化器。声明之后`x`不能再被简单赋值或复合赋值（§6.2）：否则是编译期错误。该约束是浅层的——向`const`数组的元素存储，或经由`const`类引用写字段——都是允许的。`const`适用于局部声明与形式参数；参数从实参取值，不声明初始化器。在字段上写`const`是语法错误。

单独的`;`是空语句：它什么都不做，实现SHOULD警告它被忽略。表达式不是语句：只有调用可以独立成句（§2.5），所以`5;`是语法错误。

## 6.2 赋值

赋值的目标——左值——是局部变量或参数、由成员表达式选出的字段（§4.6、§4.7）、数组下标，或`List`或`Dict`的下标（§5.7）。参数与局部变量一样可赋值。

简单赋值`x = e;`求值`e`并把值存入左值；该值必须可赋值给左值的类型（§4.12）。存储遵循第4章的值模型：结构体类型的左值存入副本（§4.6），而数组类型、类或接口的左值存入引用（§4.3、§4.7）。

复合赋值`x op= e;`，其中`op`是`+ - * / % << >>`之一（§2.5），等价于`x = x op e;`（§5.2、§5.3），但左值恰好求值一次。与二元运算符的两点不同：

- 对`<<=`与`>>=`，移位计数对照左值的声明类型检查，结果以该类型存储：左值不提升（§5.2）；
- 对`string`左值只定义了`+=`；其他复合运算符是编译期错误（§5.3）。

左值是`Dict`下标的复合赋值，在键不存在时于读取当前值处抛出可捕获的执行期错误（§4.10，第9章）。

复合赋值是语句而非表达式：它没有值，表达式中的`(x += 1)`是语法错误。对`const`局部赋值是编译期错误（§6.1）。

## 6.3 选择

`if`的条件是`bool`表达式（§5.1）。`if`的`else`绑定到最近的、尚无`else`的外层`if`（§2.7）；`else if`链是嵌套的`if`，没有`elseif`关键字。局部声明作为控制流语句的不带花括号的体是编译期错误：用段包裹它（§6.1）。

`switch`对其判别式求值一次。判别式类型必须是整数类型、浮点类型、`char`、`string`或枚举（§4.2、§4.4、§4.5）；`bool`、类、结构体、数组或`null`判别式是编译期错误。

`switch`的语法见§2.5：case子句在前，然后是可选的、位于最后的`default`子句；`default`子句在任何其他位置都是语法错误。一个case子句携带一个或多个以逗号分隔的标号；每个标号是一个表达式。在执行期，标号按子句顺序从上到下、子句内从左到右求值；第一个在§5.2的相等意义下等于判别式的标号执行其子句，该子句剩余的标号与后续子句的标号不再求值。对浮点判别式，`NaN`不匹配任何标号，`−0.0`匹配标号`0.0`（§5.2）。case标号的类型必须与判别式的类型属于同一家族；家族是：整数类型连同枚举与`char`、浮点类型、`string`。家族之间没有转换：浮点判别式上的整数标号是编译期错误。`null`标号是编译期错误。落在判别式类型取值范围之外的常量标号是编译期错误。常量值相同的两个标号——同在一个子句或分在不同子句——是编译期错误；非常量标号可以重复，首个匹配胜出。

当一个子句的语句列表执行完毕，控制传到`switch`的末尾：执行绝不从一个子句落到下一个。子句体中的`break`立即退出`switch`（§6.4）；子句体中的`continue`作用于最内层所在循环，没有所在循环时是编译期错误。

## 6.4 迭代

`while`、`do-while`与`for`的条件是`bool`表达式（§5.1）。`while`在每次迭代前测试其条件；`do-while`先运行一次体再做第一次测试。`for`在循环前运行一次其初始化子句，在每次迭代前测试其条件，并在体的每次完成后运行其步进子句；条件子句必须有，初始化与步进子句可以为空（§2.5）。初始化子句中的声明是所在作用域中的局部声明（§6.1）。步进子句限于§2.5所列形式。

`break`立即终止最内层所在循环或`switch`；在`for`中，步进子句不再运行。`continue`跳到最内层所在循环的条件测试；在`for`中，步进子句先运行。循环或`switch`之外的`break`，以及循环之外的`continue`，都是编译期错误。

`foreach (T x in src) body`迭代`src`的元素。源必须是数组、`List`、`Dict`或`string`（§4.3、§4.4、§4.10）：其他任何类型都是编译期错误。源恰好求值一次，在首次迭代之前。循环变量的声明类型必须与源的元素类型完全一致，包括数组维数（§4.3）。迭代顺序是：

- 数组：其元素按索引序；
- `List`：其元素按插入序；
- `Dict`：其键按插入序——向已存在的键存值不会移动该键；
- `string`：其码点按顺序，且循环变量必须是`char`（§4.2）。

循环变量是所在作用域中的局部声明（§6.1）：循环之后仍可见，持有最后存入的元素的值，体从未运行时则持有其类型的默认值。结构体类型的元素在每次迭代被复制进变量（§4.6）。迭代期间修改源容器未指明：元素数在循环入口捕获（§0.4）。`null`源抛出可捕获的空解引用错误（§4.7，第9章）。

## 6.5 断言

`assert(c);`要求`bool`表达式（§5.1）。值为`false`时，该语句抛出可捕获的`AssertionException`，其消息为`assertion failed`（第9章）。断言在语句的每次执行都求值：没有任何构建模式会剥离它。未捕获的`AssertionException`以退出码1终止程序（第10章）。

## 6.6 返回

`return e;`结束函数并产出`e`；`e`必须可赋值给返回类型（§4.12）。花括号形式`return { ... };`是一个以返回类型为目标类型的初始化器（§5.8）。`return;`只对`void`函数有定义：`void`函数中给出值，以及有返回类型的函数缺少值，都是编译期错误。

到达`void`函数的末尾即无值返回。到达有返回类型的函数的末尾，返回该类型的默认值（§4）。
