# 10. 执行模型与内存语义

## 10.1 值语义与引用语义

§4.1的两个值类别支配着值移动的每一个边界：赋值与初始化（§4.1）、实参传递（§7.2）、返回值（§6.6）、下标读或写（§5.7）、字段读或写（§4.6、§8.1），以及容器存入或取出（第13章）。

在边界处，值类型的值被复制：移动之后，源与目标相互独立，之后对一方的改动经另一方不可见。结构体复制复制每个字段；引用类型的字段复制其引用，于是两个结构体值此后共享那一个对象（§4.6）。

在边界处，引用类型的值复制引用：源与目标指代同一个对象，经一方做出的改动经另一方可见。每个产出引用的操作——转换（§5.5）、调用结果、容器读取——都遵循同一条规则：指代同一个对象，绝不是副本。

`string`值是不可变文本的句柄：边界复制句柄，而不可变性使这种共享不可观察（§4.4）。标量基本类型、`string`或枚举值进入`Object`位置时在那里被装箱——包进一个堆对象（§4.9）——拆箱则把值读回来（§5.5）。

有两个操作以不同的方式移动值：

- `out`实参在调用期间充当调用方变量的别名，并在返回时写回最终值（§7.2）；
- 把方法绑定为函数值会捕获接收者对象的引用，只要该函数值存活，就使那个对象保持可达（§7.4、§10.2）。

## 10.2 生命周期与垃圾回收

对象——类实例、结构体记录、数组、函数值与字符串——生活在由实现管理的堆中。语言不提供释放操作：程序从不释放对象，回收也不运行用户代码（没有终结器，也没有析构器）。

若一个对象能经由引用从根出发找到，它就是*可达*的：活动函数帧的活跃槽（参数、局部变量、临时值与暂存槽）、可达对象的字段、可达容器的元素、存活函数值被捕获的接收者，以及宿主持有的引用。实现做出两条承诺：

- 可达对象绝不被回收；
- 不可达对象MAY在任何时刻被回收；回收何时发生是*未指明*的（§0.4）。

由于回收不运行用户代码且其时机未指明，程序无法观察一个对象何时——或者是否——被回收。结构体记录由其持有者（一个局部槽、一个字段，或数组或容器的一个元素）拥有，并随之一起变为不可达。

实现无法为新对象取得内存时会发生什么，是*未指明*的。

## 10.3 程序的进入与退出

程序有一个入口函数：显式的`int main()`，或从脚本体合成的`int main()`（§3.2）。执行从调用它开始；它不带参数。

入口返回的值成为进程退出状态。实现把入口的32位返回值原样传给宿主；宿主如何把它呈现给观察者是宿主行为，不是语言行为：POSIX shell把值截断到低8位（`return 300;`被观察为`44`），而cmd、PowerShell与Python观察到完整的无符号32位值（`return -1;`被观察为`4294967295`）。退出状态会被其他工具检查的程序应当保持在`0`到`255`之内。

到达入口函数末尾会返回`int`的默认值，因此程序以状态`0`退出（§6.6）。未捕获的异常使程序以状态`1`结束（§9.1），宿主级执行期错误（§7.1）同样使程序以状态`1`结束。

## 10.4 未指明行为

§0.4定义了*未指明*与*实现定义*。本节汇集执行模型的未定之点：

- 垃圾回收器的算法与回收的时机（§10.2）；
- 内存耗尽时的行为（§10.2）；
- 未被某节固定的异常消息的文本（§9.3）；
- 宿主对未捕获异常或宿主级错误的报告形式（§9.1、§7.1）。

某节若让一个行为保持开放，会用这些术语之一说明；其他地方的行为是被规定的。
