# 9. 执行模型

本章规定值在语言边界上如何移动、对象存活多久、程序如何进入与退出，以及哪些行为保持开放。值语义与引用语义（§9.1）与未定之点（§9.4）在本页；对象生命周期与回收（§9.2）有独立页面，程序的进入与退出（§9.3）亦然。

## 9.1 值语义与引用语义

§4.1的两个值类别支配着值移动的每一个边界：赋值与初始化（§4.1）、实参传递（§7.2）、返回值（§6.6）、下标读或写（§5.7）、字段读或写（§4.7.4、§4.8.1），以及容器存入或取出（第13章）。

在边界处，值类型的值被复制：移动之后，源与目标相互独立，之后对一方的改动经另一方不可见。结构体复制复制每个字段；引用类型的字段复制其引用，于是两个结构体值此后共享那一个对象（§4.7）。

在边界处，引用类型的值复制引用：源与目标指代同一个对象，经一方做出的改动经另一方可见。每个产出引用的操作——转换（§5.5）、调用结果、容器读取——都遵循同一条规则：指代同一个对象，绝不是副本。

`string`值是不可变文本的句柄：边界复制句柄，而不可变性使这种共享不可观察（§4.3）。标量基本类型、`string`或枚举值进入`Object`位置时在那里被装箱——包进一个堆对象（§4.11）——拆箱则把值读回来（§5.5）。

有两个操作以不同的方式移动值：

- `out`实参在调用期间充当调用方变量的别名，并在返回时写回最终值（§7.2）；
- 把方法绑定为函数值会捕获接收者对象的引用，只要该函数值存活，就使那个对象保持可达（§7.4、§9.2）。

## 9.4 未指明行为

§0.4定义了*未指明*与*实现定义*。本节汇集执行模型的未定之点：

- 垃圾回收器的算法与回收的时机（§9.2）；
- 内存耗尽时的行为（§9.2）；
- 未被某节固定的异常消息的文本（§8.3）；
- 宿主对未捕获异常或宿主级错误的报告形式（§8.1、§7.1）。

某节若让一个行为保持开放，会用这些术语之一说明；其他地方的行为是被规定的。
