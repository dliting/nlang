# 三种运行方式

### 1. 在nide中（推荐）

1. 启动nide（安装包内位于`bin\`下），菜单文件 → 打开 → 项目...，选`examples/hello_project/hello_project.nproj`。
2. 左侧「解决方案」树双击main.n打开编辑器。
3. 菜单构建 → 构建项目，然后运行 → 开始运行（Ctrl+F5）；程序直接在输出窗口「输入输出」页的嵌入系统终端里运行。F5启动的是调试会话，见[在nide中调试](debugging.md)。

「输入输出」页是一个嵌入的系统终端：程序经由伪终端（PTY，pseudo terminal）直接在终端里运行——Windows上这一层是伪控制台（ConPTY，Windows pseudo console）——所见与在系统终端中手动运行一致，颜色等终端转义序列照常渲染。程序运行期间直接键入即与程序交互：按键原样送往程序，回显由程序一侧完成；程序等待输入时行首显示`> `提示符（同一程序在系统终端里直接运行也如此）；程序结束后键盘输入不再接收。终端操作：Ctrl+C有选区时复制选中内容，无选区时向程序发送中断信号；Ctrl+V粘贴（多行文本自动压成一行）；拖选即选中，选中内容可复制；滚轮翻动回看历史输出。已知限制：回看至多保留10000行，连字字体的连字效果不支持。

### 配置nide

菜单工具 → 选项打开设置对话框，四项设置：

- **语言**：跟随系统语言 / 中文 / English。切换后**重启nide生效**（保存后立即弹出重启提示）。帮助菜单按当前语言选择对应文档树，页面缺失时回退另一树。
- **全局构建输出目录**：留空时用缺省位置——用户临时目录下的`nlang-nide`子目录（输入框占位符显示的就是它；**占位符只是提示，字段值不做环境变量展开**——不要往框里填`%TEMP%\xxx`字面量）。设置后从下一次构建起生效，优先级：工程`.nproj`的`outputDir` >此目录 > 工程目录；独立`.n`文件直接用此目录。
- **工具栏图标尺寸**：小（32×32）/ 大（48×48）。切换即时生效，无需重启。
- **编辑器字体大小**：全部代码编辑器共用的字号，单位磅（pt），范围6～48。确认后即时生效；编辑器内Ctrl+滚轮同样缩放（每档±1磅），两处写同一设置，跨会话保存。

### 最近打开

菜单「文件 → 最近打开」跨会话记录解决方案（.nsln）、项目（.nproj）与文件，至多10条，按最近使用排序。条目在打开、新建文件、另存为文件时记录。重命名在原位更新。已不存在的条目在菜单中隐藏，但保留在记录里，直到被更新的条目挤出；同名条目自动追加目录名后缀消歧。「清空最近列表」一键清空整份清单。

### 项目属性

菜单项目 → 项目属性打开工程对话框，四个字段：

- **名称**：工程名，即`.nproj`文件名。须非空且不含路径分隔符（`/`或`\`）。新建时填写；已保存的工程不可改名。
- **位置**：工程根目录（`.nproj`文件所在目录）。新建时填写；已保存的工程不可移动。
- **输出目录**：最终`.npkg`的输出位置；留空 = 工程目录自身。ncc消费，优先级同「配置nide」的全局构建输出目录。
- **中间目录**：预留字段，当前工具链（ncc）尚未消费，暂不使用。

### 2. 命令行

在仓库根目录运行；安装包用户在安装根目录运行（ncc/nvm位于`bin\`下）：

    ncc build examples/hello.n -o hello.ncu   # 编译nvm hello.ncu                             # 运行（退出码42）

安装包内未设置PATH时使用`bin\ncc build ...`、`bin\nvm <name>.ncu`。

多文件项目用`-p`指定`.nproj`，`-o`指定输出位置（产物是`.npkg`程序包）：

    ncc build -p examples/hello_project/hello_project.nproj -o hello_project.npkg
    nvm hello_project.npkg

完整参考（全部标志、默认输出位置、ndb调试器与ndisasm）见[命令行工具](../cli-tools/overview.md)一章。
