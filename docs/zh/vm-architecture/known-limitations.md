# 已知限制


1. **退出码范围**：Windows 上进程退出码是 8 位（0-255）。测试预期值
   不得超过 255。
2. **没有 super() 调用**：不会自动调用祖先构造函数。
3. **struct 没有方法**：struct 只承载数据。需要行为时请用 class。
4. **没有用户自定义泛型**：不支持 `class Foo<T> { ... }`。编译器只
   识别内建泛型类（`List<T>`、`Dict<K,V>`）。
5. **`List<int>` 存储开销**：每个基元元素都装箱进一个堆槽位
   （`RTK_Boxed`）。对值密集的列表，规划中的出路是带非装箱存储的
   `IntList` 特化（推迟到性能分析表明确有需要）。null 哨兵 bug
   （OP_Box 对 val==0 跳过分配）已在 P3.10 修复。
6. **`List<struct>` 值语义**：把同一个 struct 变量加入两次，共享的
   是底层堆槽位（装箱是引用语义）。需要独立元素时请使用各自的
   struct 实例。
7. **字符串池无界增长**：拼接产生的字符串会进入字符串池，但永远不
   被回收。
