# 类型


### 基本类型

| 类型   | 大小  | 说明          |
|--------|-------|----------------------|
| int    | 4 字节 | 32 位有符号整数 |
| float  | 4 字节 | 32 位 IEEE 754 浮点 |
| string | 4 字节 | 指向字符串对象仓的 1-based 句柄（0 = null，读作 ""） |

**数字字面量**：整数字面量可用指数记法——`2e5` 即 200000。值必须为
整数且落在 32 位整数范围内；`1e30`（超界）与 `2e-1`（= 0.2，带小数
部分）都是编译错误。float 字面量必须带小数点，也可用指数（`1.0e30`、
`2.5e-3`）；裸写的 `1e30` 是 int 字面量，不是 float。

**字符串编码**：字符串字面量以其 UTF-8 字节序列存入模块字符串常量表。
`string.length()` 返回**字节数**，不是 Unicode 码点数——
`"héllo".length()` 是 6（5 个码点，但 `é` 在 UTF-8 中占 2 字节）。
真正的 UTF-8 码点迭代推迟到后续阶段。

### 复合类型

| 类型   | 语义 | 存储          | 说明              |
|--------|-----------|------------------|--------------------------|
| enum   | 值     | int32            | 具名整数常量  |
| struct | 值     | 堆索引（赋值时深拷贝） | 值类型聚合 |
| class  | 引用       | 堆索引       | 引用类型对象   |

### 字符串的实现与内存语义

字符串在运行期是**不可变对象**：拼接、截取等操作都产出新的内容，
既有对象的内容永不改变。string 槽位持有指向字符串对象仓的句柄，
句柄 0 表示 null，读取时按空串处理。

- **常量随模块执行存活**：源代码里的字符串字面量在模块开始执行时
  物化为常驻对象，整个执行期间不会被回收。
- **短串驻留重用**：不超过 40 字节的运行期字符串按内容驻留——
  相同内容只保留一份对象。`==` 比较的仍然是内容，语义不变。
- **追加 O(1)**：`s = s + x` 先记录为一个拼接节点，首次读取时才
  展平为实际内容，循环追加不会逐步拷贝整串。
- **内存有界**：不再被引用的字符串对象由垃圾回收器回收，长时运行
  的程序（如持续构建提示词的循环）内存占用不会无限增长。

### Null

class 类型的变量可以为 null（表示为堆索引 0）。对 null 访问字段或
方法会抛出 `NullPointerException`（可经 try/catch 捕获）。
