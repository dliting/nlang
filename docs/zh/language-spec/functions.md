# 函数


```nlang
int add(int a, int b) {
    return a + b;
}
```

- 参数：int/float/string/enum 按值传递，struct 按值传递（深拷贝），
  class 按引用传递
- 返回类型：int、float、string、enum、struct（深拷贝）、class（引用）
- 递归：支持，有深度上限（默认 1000）

### void 函数

函数可以声明 `void` 返回类型——不返回值。适用于自由函数、class 方法
（任意修饰符组合，如 `public static void f()`）与接口成员（与所有
接口成员一样仍要求 `public`）。

```nlang
void log(int level) {
    if (level == 0) { return; }   // 裸 `return;` 提前退出
}

class Counter {
    public int hits;
    public void bump(int by) { this.hits = this.hits + by; }
}
```

- 裸 `return;` 提前退出；void 函数不能 `return expr;`
- 有返回值的函数不能用裸 `return;`（编译错误）
- void 调用的结果不可被消费——赋值、作操作数、返回它都是编译错误
  （调用必须是表达式语句：`log(3);`）
- void 函数可与 out 参数组合，实现只产生副作用的调用
- 跨模块：被导入的 void 桩同样不携带可消费的结果；消费侧适用同样的
  「结果不可消费」规则
- `void` 在任何其他位置都不是合法类型（局部变量、字段、参数、数组
  元素——一律在解析阶段拒绝）

### 默认参数

函数参数可以带默认值。默认值可出现在任意位置（不限于末尾）。默认
表达式可以引用更早的形参。

```nlang
int foo(int a, int b = 0) { return a + b; }
int foo(int a, int b = a + 1) { return b; }       // 引用更早的形参
int foo(int a, int b = 0, int c) { return c; }     // 默认值不在末尾
```

- `foo(5)` → `b` 取默认值
- `foo(5, 10)` → `b` 是 10，默认表达式不求值
- 默认表达式在调用点求值（不在声明处）
- 默认表达式与参数类型不匹配是编译错误

### 具名实参

实参可用 `name = expr` 语法按名传递。位置实参必须先于具名实参。

```nlang
int foo(int a, int b) { return a * 10 + b; }
foo(a = 5, b = 7);     // 具名，任意顺序
foo(5, b = 7);          // 混合：先位置后具名
foo(b = 7, a = 5);      // 具名，逆序
```

错误：
- `foo(b = 2, 1)`——位置实参出现在具名实参之后：编译错误
- `foo(1, a = 2)`——`a` 被重复绑定：编译错误
- `foo(c = 1)`——未知的参数名：编译错误

### 带默认值的重载决议

存在多个重载时，编译器计算类型距离得分并选择最佳匹配。两个或更多
重载以相同距离匹配时，调用有歧义，报告编译错误。

```nlang
int foo(int a) { return 100; }
int foo(int a, int b = 0) { return 200; }
foo(5, 10);   // OK：第二个重载（2 个实参匹配 2 个形参）
foo(5);       // 错误：有歧义（两个重载都接受 1 个实参）
```

### out 参数

以 `out` 声明的参数是写回槽位：调用者的局部变量被预置进被调方的
栈帧槽位；调用返回后，被调方的值被拷回调用者的变量。

```nlang
int divide(int a, int b, out int rem) {
    rem = a % b;
    return a / b;
}
int r = 0;
int q = divide(17, 5, out r);  // q=3, r=2
```

**语义：**
- out 参数是 **inout**：被调方看到的参数局部变量初始值是调用者的
  当前值。
- 写回发生在调用返回之后，按槽位顺序进行。
- 调用的返回值**先于** out 写回存入结果变量，因此
  `int x = f(out x)` 为返回赋值读到旧的 `x`，随后被调方的输出覆写
  `x`。

**限制：**
- out 实参必须是**局部变量**（不能是字段、数组元素或任意表达式）。
  否则编译错误。
- out 参数必须是 **4 字节标量或 class 类型**（struct 不行）。struct
  的可变尺寸值语义与固定槽位写回机制不兼容。
- 虚/接口分派调用不支持 `out`（编译期不知道具体被调方）。
- 构造函数（`new`）与 `super()` 调用不支持 `out`。
- 跨模块被导入的函数不支持 `out`（`.nmod` 桩不携带 out 标记）。
- 每次调用至多 32 个 out 参数。
- `out` 是保留关键字。

### 原生函数

标记 `native` 的函数声明**没有函数体**——实现由嵌入宿主在运行期
提供：

```nlang
native int natAdd(int a, int b);
native float natFAdd(float a, float b);
native void natPing();

int main() {
    return natAdd(20, 22);  // 42 —— 分派给宿主
}
```

**模型。**声明编译为只携带签名的函数记录（无字节码）。调用点上，
VM 在宿主注册的原生函数表中按名查找，直接
以调用方暂存的实参单元调用原生实现：

- ABI：实参 `i` 是 `args[i*4]` 处的裸 4 字节单元——小端
  `int32`/`float` 位或堆索引，与内建函数 ABI 相同。原生实现把 4 字节
  返回值写入 `ret`（`void` 原生函数可为 null）。
- 调用宿主从未注册的原生函数会在调用点抛错
  （`native function not registered: <name>`）——绝不静默产生垃圾。
- 默认参数可用（分派前在调用点填充），跨模块导入亦然（默认值随
  native 标志一起序列化进模块文件）。

**限制：**
- `native` 声明**不得有函数体**——编译错误。实现归宿主所有。
- **不支持 out 参数**——写回需要被调方栈帧，而原生函数没有。编译
  错误；VM 对手工构造的模块执行同样检查。
- 表只按**声明名**为键。宿主注册方负责匹配声明的签名；不匹配
  （如对 int 原生函数声明 `native string`）会产出垃圾输出，而不是
  类型错误。两个模块声明同名原生函数时共享一个表条目。
- 跨模块：导入含原生函数的 `.nmod` 的模块经同一张表调用它们
  （native 标志在模块合并后保留）。
- class 成员的 `native` 方法可用：分派经常规方法路径到达原生实现，
  `this` 位于 `args[0]`（接收者的堆索引），后接声明的参数——与
  字节码调用约定一致。因此同一实现绑定为方法时，宿主原生函数在
  `args[(1+j)*4]` 读用户参数 `j`；绑定为自由函数时在 `args[j*4]`。
  把一个实现同时注册成两种形状属于签名不匹配（见上）。
- 超出裸 4 字节 ABI 的 string/struct/class 实参编组暂不支持。
- **测试宿主说明**：`ncc` 与 `nvm` 二进制是测试宿主——它们总是注册
  `natAdd`、`natConst`、`natFAdd` 与 `natPing`，让测试套件能演练
  绑定路径。生产嵌入方的宿主不会注册这些测试名字；对这样的宿主调用
  这些名字的脚本会在运行期得到
  `"native function not registered"`。

### 栈帧布局

每个函数的局部栈帧按其函数体动态定尺寸：

```text
[this?][形参][返回值槽][暂存槽 1-4][调用参数区(N)][求值暂存区(峰值深度)][用户局部变量...]
```

- **N** = 本函数体内观察到的最大被调形参个数（方法再加 `this` 的
  槽 0）。调用参数区是 `OP_CallFunc`/`OP_CallMethod` 消费的
  最终着陆区。
- **峰值深度** = 所有调用点（含嵌套调用）同时需要的求值暂存区槽位
  峰值（如 `foo(helper(5), helper(10))` 需要 4 个槽位：`foo` 的实参
  2 个 + 内层 `helper` 调用 2 个）。

求值暂存区是不相交的、栈式纪律的暂存区。每次发射调用实参时按
栈式作用域认领一个切片，退出时释放。绑定发射到
被认领的切片；批量拷贝循环随后在调用前一刻把它们搬到
调用参数区。这意味着内层调用的绑定永远不会覆写外层调用已发射
的绑定。

64 个形参的合理性上限防止不合理的超大栈帧；
超出即声明期错误。
