# mnist_mlp — a two-layer perceptron on MNIST

The acceptance program for the v0.12.7 array/tensor surface: a
784 → 100 → 10 perceptron trained with mini-batch SGD on a 2000-record
MNIST subset. The forward and backward passes are written in batch
matrix form — `matmul` for the linear maps, bias broadcast for the
offsets, `sum(·, axis)` for the bias gradients — over zero-copy views
of the loaded data (each batch is a contiguous row-block slice).

## Layout

| File | Role |
|---|---|
| `main.n` | entry point: training loop, acceptance gate |
| `data.n` | loading (`fs.readFloats` / `fs.readBytes`) and batching |
| `layers.n` | forward, softmax, cross-entropy, backprop, SGD step |
| `mnist_mlp.nproj` | project manifest (three compilation units) |
| `data/` | the extracted subset + provenance (see `data/README.md`) |

The three units compose through `import` (`import layers;` in
`main.n`, `layers.forward(...)` at the call sites).

## Build and run

From this directory:

    ncc build -p mnist_mlp.nproj -o mnist_mlp.npkg
    nvm mnist_mlp.npkg

The program prints the mean loss per epoch and the test accuracy, and
exits 0 only when training reduces the loss and the frozen baseline
accuracy is met.

## Determinism and the frozen baseline

Everything is deterministic: the data keeps its file order (already
shuffled upstream), and the weights come from `math.srand(42)`-seeded
`math.random()`. A given toolchain build reproduces the same numbers.
The first measured run reached **0.897** test accuracy in 9.5 s
(40 epochs); the assert gate sits at **0.85**. Literature for
2000-record MNIST subsets reports 88–92% — the frozen value is below
the zone floor and 4.7 points under the measurement, so float noise
cannot trip it while a real kernel or view regression does.

## Regenerating the data

`data/` is generated by `tools/mnist_subset.py` (run from the
repository root with the `py313` interpreter). The script downloads the
official IDX files from the public mirror, verifies the upstream
SHA256, and writes the first 2000/1000 records as headerless binaries:
images normalized to `float32` little-endian (`fs.readFloats` reads
them directly), labels as one unsigned byte each (`fs.readBytes`).
Provenance — URLs, hashes, subset policy — is recorded in
`data/README.md`.
